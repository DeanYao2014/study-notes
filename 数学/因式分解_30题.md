# 因式分解 · 30题

> 七年级下册 | 提公因式 → 公式 → 十字相乘 → 分组 → 综合

---

## 解题流程

```
一提 → 二套(公式) → 三十字 → 四分组 → 五检查(还能再分吗？)
```
