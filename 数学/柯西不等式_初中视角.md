# 柯西不等式（Cauchy-Schwarz）· 初中视角

---

## 一、什么是柯西不等式？

### 🟢 基础：二维形式（初中涉及）

$$(a^2+b^2)(x^2+y^2) \geq (ax+by)^2$$

- **等号成立条件**：当 $\dfrac{a}{x}=\dfrac{b}{y}$（两个括号里的数对应成比例）
- **通俗理解**：两组数的"平方和的乘积" ≥ "乘积之和的平方"

**极简验证**：取 $a=1,b=2$，$x=3,y=4$
- 左边：$(1+4)\times(9+16)=5\times25=125$
- 右边：$(1\times3+2\times4)^2=(3+8)^2=121$
- $125 > 121$ ✓

### 🟡 考点：n维形式（了解）

$$(a_1^2+a_2^2+\cdots+a_n^2)(b_1^2+b_2^2+\cdots+b_n^2) \geq (a_1b_1+a_2b_2+\cdots+a_nb_n)^2$$

不要求掌握，知道二维形式就够用。

### 🔴 拔高：向量几何直觉

把 $(a,b)$ 和 $(x,y)$ 看作平面上两个向量。它们的点积 = $ax+by$ = $|\vec{u}||\vec{v}|\cos\theta$，而 $|\cos\theta|\leq1$，所以 $|点积| \leq |\vec{u}|\cdot|\vec{v}|$，两边平方即得柯西不等式。

**等号成立就是两个向量平行（同向或反向）。** 这个几何画面能帮你直觉理解为什么是"成比例"时取等号。

## 二、初中三类实际应用

### 题型1：平方和定值 → 求线性式最值

> **例题**：已知 $x^2+y^2=1$，求 $3x+4y$ 的最大值和最小值。

**🔴 柯西秒杀（考场验证答案用）**：

$$(3^2+4^2)(x^2+y^2) \geq (3x+4y)^2$$

$$25 \times 1 \geq (3x+4y)^2 \quad\Rightarrow\quad -5 \leq 3x+4y \leq 5$$

最大值 **5**，最小值 **-5**。等号当 $\dfrac{x}{3}=\dfrac{y}{4}$ 即 $x=\dfrac{3}{5}, y=\dfrac{4}{5}$ 时取得。

**🟡 初中规范解法：判别式法（Δ法）**：

步骤：设目标 = t → 消元得二次方程 → Δ ≥ 0 → 解出t范围。

1. 设 $t = 3x+4y$，则 $y = \dfrac{t-3x}{4}$
2. 代入 $x^2+y^2=1$：
   $$x^2 + \frac{(t-3x)^2}{16} = 1$$
3. 去分母整理：
   $$25x^2 - 6tx + (t^2-16) = 0$$
4. $x$ 为实数 → $\Delta \geq 0$：
   $$\Delta = (-6t)^2 - 4 \times 25 \times (t^2-16) \geq 0$$
   $$36t^2 - 100t^2 + 1600 \geq 0 \quad\Rightarrow\quad |t| \leq 5$$

> **套路总结**：设目标 = t → 消元 → Δ ≥ 0 → 解t范围。这是考场最稳妥的写法。

---

### 题型2：线性定值 → 求平方和最值

> **例题**：已知 $2x+3y=5$，求 $x^2+y^2$ 的最小值。

**🔴 柯西秒杀**：

$$(2^2+3^2)(x^2+y^2) \geq (2x+3y)^2 = 25$$

$$13(x^2+y^2) \geq 25 \quad\Rightarrow\quad x^2+y^2 \geq \frac{25}{13}$$

最小值 $\dfrac{25}{13}$。

**🟡 初中规范解法：消元 + 配方**：

1. 由 $2x+3y=5$ 得 $y = \dfrac{5-2x}{3}$
2. 代入目标：
   $$S = x^2 + \frac{(5-2x)^2}{9} = \frac{13x^2-20x+25}{9}$$
3. 对分子配方：
   $$13x^2-20x+25 = 13\left(x-\frac{10}{13}\right)^2 + \frac{225}{13}$$
4. 当 $x=\dfrac{10}{13}$ 时取最小值，$S_{\min} = \dfrac{25}{13}$

> **套路总结**：线性约束 → 消元变单变量 → 二次函数配方求最值。

---

### 题型3：和为定值 → 求分式和的最值

> **例题**：$a>0, b>0$，$a+b=1$，求 $\dfrac{1}{a}+\dfrac{1}{b}$ 的最小值。

**🔴 柯西秒杀**：

$$(a+b)\left(\frac{1}{a}+\frac{1}{b}\right) \geq (1+1)^2 = 4$$

因为 $a+b=1$，所以 $\dfrac{1}{a}+\dfrac{1}{b} \geq 4$，最小值 **4**。

**🟡 初中规范解法：均值不等式**：

1. $\dfrac{1}{a}+\dfrac{1}{b} = \dfrac{a+b}{ab} = \dfrac{1}{ab}$
2. 由均值不等式：$ab \leq \left(\dfrac{a+b}{2}\right)^2 = \dfrac{1}{4}$
3. 所以 $\dfrac{1}{ab} \geq 4$，当 $a=b=\dfrac{1}{2}$ 时取等

> **套路总结**：正数 + 和为定值 → 均值不等式处理积 → 注意"一正二定三相等"三个条件。

## 三、初中解法工具箱（总结）

| 方法 | 适用场景 | 核心步骤 | 难度 |
|------|---------|---------|------|
| **判别式法（Δ法）** | 二次约束 + 一次目标（或反之） | 设t → 消元 → Δ≥0 → 解t | ⭐⭐ |
| **配方法** | 单变量二次函数 | 配方 → 平方最小值=0 | ⭐ |
| **均值不等式** | 正数 + 和/积定值 | $a+b \geq 2\sqrt{ab}$ | ⭐⭐ |

**选择原则**：
- 二元一次约束 + 二元二次目标 → **消元配方法**
- 二元二次约束 + 二元一次目标 → **判别式法**
- 正数 + 分式和/积 → **均值不等式**

## 四、小练习

**练1**：$x^2+y^2=4$，求 $x+2y$ 的最大值。

**练2**：$3x+4y=10$，求 $x^2+y^2$ 的最小值。

**练3**：$a>0,b>0$，$\dfrac{1}{a}+\dfrac{1}{b}=2$，求 $a+b$ 的最小值。

**练1答案**：最大值 $2\sqrt{5}$

判别式法：设 $t=x+2y$，$y=\frac{t-x}{2}$，代入 $x^2+y^2=4$：
$$x^2+\frac{(t-x)^2}{4}=4 \;\Rightarrow\; 5x^2-2tx+t^2-16=0$$
$\Delta = 4t^2-20(t^2-16) \geq 0 \;\Rightarrow\; t^2 \leq 20 \;\Rightarrow\; |t| \leq 2\sqrt{5}$

柯西验证：$(1^2+2^2)(x^2+y^2) \geq (x+2y)^2 \;\Rightarrow\; 5\times4 \geq t^2 \;\Rightarrow\; |t| \leq 2\sqrt{5}$

**练2答案**：最小值 $4$

配方法：$y=\frac{10-3x}{4}$，$S=x^2+\frac{(10-3x)^2}{16}=\frac{25x^2-60x+100}{16}$
配方：$25(x-\frac{6}{5})^2+64$，当 $x=\frac{6}{5}$ 时 $S_{\min}=\frac{64}{16}=4$

柯西验证：$(3^2+4^2)(x^2+y^2) \geq (3x+4y)^2=100 \;\Rightarrow\; S \geq 4$

**练3答案**：最小值 $2$

均值：$2=\frac{1}{a}+\frac{1}{b} \geq 2\sqrt{\frac{1}{ab}} \;\Rightarrow\; ab \geq 1$
再由 $a+b \geq 2\sqrt{ab} \geq 2$，当 $a=b=1$ 时取等

柯西验证：$(a+b)(\frac{1}{a}+\frac{1}{b}) \geq 4 \;\Rightarrow\; (a+b)\times2 \geq 4 \;\Rightarrow\; a+b \geq 2$

## 五、核心要点

> **柯西不等式就是把"平方和 × 平方和 ≥ 乘积和的平方"这个恒等式当成工具用。初中考试不能直接写"由柯西不等式得"，但你可以用它心算验证答案，然后用判别式/配方/均值规范写出过程。**
