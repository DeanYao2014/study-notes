# 数学常见应用题解析 · 统一框架

> **核心思想**：小学奥数到初中，应用题表面千变万化，底层只有不到10种数学模型。  
> 本文按**数学结构**分类，而非按表面题型罗列——掌握一个模型，吃透一类题。

---

## 一、速率叠加模型（"牛吃草"家族）

**统一公式**：`总量 = 净速率 × 时间`

### 1.1 总量动态变化型（经典牛吃草）

**特征**：总量自身在增减，另有外力在消耗。

| 题型 | 总量类比 | 自然增减 | 消耗/产出 |
|------|----------|----------|-----------|
| 牛吃草 | 原有草量 | 草每天长 | 牛每天吃 |
| 水池注排水 | 原有水量 | 注水管注水 | 排水管排水 |
| 排队检票 | 原有人数 | 新来人排队 | 窗口检票 |
| 资源消耗 | 原有资源 | 资源再生 | 消耗速度 |

**通用解法**（四步）：
1. 设原有总量 = `y₀`，自然增减速率 = `v₁`，消耗速率 = `v₂`
2. 列两组条件：`(v₂ − v₁) × t₁ = y₀`，`(v₂' − v₁) × t₂ = y₀`
3. 消元求 `v₁`（生长速率），再求 `y₀`
4. 带入问题条件求解

### 1.2 总量固定型（行程/工程）

**特征**：总量不变，只有速率叠加。

| 题型 | 总量 | 正速率 | 负速率/相对 |
|------|------|--------|-------------|
| 相遇问题 | 总路程 S | v₁、v₂ | 无（相加） |
| 追及问题 | 差距 S | 快者 v₁ | 慢者 v₂（相减） |
| 环形跑道 | 圈长 | v₁、v₂ | 同向减、反向加 |
| 合作做工 | 总工作量 | 各自效率 | 无 |

**关键公式**：
- 相遇时间 = `S ÷ (v₁ + v₂)`
- 追及时间 = `S ÷ (v₁ − v₂)`（v₁ > v₂）
- 合作时间 = `总工作量 ÷ (效率₁ + 效率₂)`

### 1.3 变形子类

| 题型 | 特殊之处 | 处理方法 |
|------|----------|----------|
| 流水行船 | 水速叠加到船速 | 顺水 v = v船+v水，逆水 v = v船−v水 |
| 火车过桥 | 路程 = 桥长 + 车长 | 把车长加到路程里 |
| 钟表问题 | 追及模型，单位是角度 | 分针速度 6°/min，时针 0.5°/min |

### 经典例题

**例1 · 牛吃草**
一片匀速生长的草地，27头牛6天吃完，23头牛9天吃完。问：21头牛几天吃完？

> **解**  
> 设原有草量 y₀，每天长草 v₁，每头牛每天吃 1 份。  
> 27头6天：27×6=162 = y₀ + 6v₁  
> 23头9天：23×9=207 = y₀ + 9v₁  
> 两式相减：45 = 3v₁ → **v₁=15**（每天长15份草）  
> 代入：y₀ = 162−6×15 = **72**（原有72份草）  
> 21头吃 t 天：21t = 72+15t → 6t=72 → **t=12天**

**例2 · 相遇与追及**
甲速5km/h，乙速3km/h。(1)相向而行，2h相遇，AB距离？(2)若AB=16km，同向甲追乙，几小时追上？

> **解**  
> (1) S = (5+3)×2 = **16km**  
> (2) t = 16÷(5−3) = **8h**

**例3 · 水池注排水**
一水池，进水管单独注满需3h，排水管单独排空需4h。两管同时开，几小时注满？

> **解**  
> 设总容量为1，进水速率 1/3，排水速率 1/4。  
> 净速率 = 1/3 − 1/4 = 1/12  
> 时间 = 1 ÷ (1/12) = **12h**  
> （此题本质=牛吃草：原有0份草，注水=生长，排水=吃草）

## 二、比例不变模型（浓度 / 利润 / 分数）

**统一公式**：`目标量 = 总量 × 比例`

### 2.1 浓度问题

**核心恒等式**：溶质质量不变

```
浓度 = 溶质 ÷ 溶液 × 100%
溶质 = 溶液 × 浓度
```

**典型子类型**：

| 类型 | 方法 |
|------|------|
| 稀释（加水） | 溶质不变，溶液增大 → 浓度降低 |
| 浓缩（蒸发） | 溶质不变，溶液减小 → 浓度升高 |
| 加浓（加溶质） | 溶剂不变，溶质增加 |
| 混合（两溶液混） | 溶质总和不变 |

**十字交叉法**（混合专用）：
```
高浓度 a           |b − c|
              ↘   浓度c    ↗
低浓度 b           |c − a|

质量比 = |b − c| : |c − a|
```

### 2.2 利润/折扣问题

| 名词 | 公式 |
|------|------|
| 利润 | 售价 − 成本 |
| 利润率 | 利润 ÷ 成本 × 100% |
| 售价 | 成本 × (1 + 利润率) |
| 折扣后 | 原价 × 折扣 ÷ 10 |

**核心套路**：亏本卖 vs 盈利卖的差价 → 用差值列方程。

### 2.3 分数/百分数应用题

**三大基本量**：
```
单位"1" × 分率 = 对应量
```

| 已知 | 求 | 运算 |
|------|-----|------|
| 单位"1" + 分率 | 对应量 | 乘 |
| 对应量 + 分率 | 单位"1" | 除 |
| 部分 + 整体 | 分率 | 除 |

**量率对应**是解分数应用题的核心技巧——找到具体量和它对应的分率。

### 经典例题

**例4 · 浓度混合**
40%盐水500g与20%盐水300g混合，求混合后浓度。

> **解**  
> 溶质总和 = 500×40% + 300×20% = 200+60 = 260g  
> 溶液总和 = 500+300 = 800g  
> 浓度 = 260÷800×100% = **32.5%**  
> 十字交叉验证：40%→|20−32.5|=12.5，20%→|40−32.5|=7.5  
> 质量比 = 12.5:7.5 = 5:3 = 500:300 ✓

**例5 · 利润折扣**
进价120元，按40%利润定价，再打八折出售。实际利润率？

> **解**  
> 定价 = 120×(1+40%) = 168元  
> 售价 = 168×0.8 = 134.4元  
> 利润 = 134.4−120 = 14.4元  
> 利润率 = 14.4÷120×100% = **12%**

**例6 · 量率对应（分数应用题）**
一筐苹果，第一天吃 1/3，第二天吃剩下的 2/5，还剩12个。原来有多少？

> **解**  
> 第一天剩：1−1/3 = 2/3  
> 第二天吃：2/3 × 2/5 = 4/15  
> 共吃：1/3+4/15 = 5/15+4/15 = 9/15 = 3/5  
> 剩下：1−3/5 = 2/5 → 对应12个  
> 原来：12÷(2/5) = **30个**

## 三、总量守恒模型（和差倍 / 盈亏 / 年龄）

**统一公式**：`若干个量满足总和 = 常数`

### 3.1 和差问题

```
大数 = (和 + 差) ÷ 2
小数 = (和 − 差) ÷ 2
```

画线段图一招解决。

### 3.2 和倍 / 差倍问题

```
和倍：小数 = 和 ÷ (倍数 + 1)
差倍：小数 = 差 ÷ (倍数 − 1)
```

**关键**：找准"1份"对应多少。

### 3.3 盈亏问题

**统一公式**：
```
份数 = (盈 + 亏) ÷ 两次每份差
```

| 情况 | 公式分子 |
|------|----------|
| 一盈一亏 | 盈 + 亏 |
| 两盈 | 大盈 − 小盈 |
| 两亏 | 大亏 − 小亏 |

**一年级口诀**："盈盈相减，亏亏相减，一盈一亏相加"

### 3.4 年龄问题

**核心**：年龄差永远不变（守恒量！）

- 年龄和 → 每年总增 n人×1岁
- 年龄差 → 永恒不变
- 年龄倍数 → 随年龄增大而变小

**解法套路**：抓住"差不变"，若干年后转化为差倍问题。

### 3.5 鸡兔同笼

**假设法**（不记公式也能做）：

1. 假设全是鸡 → 算出总腿数 → 比实际少多少
2. 每只兔比鸡多 2 条腿
3. 兔数 = 少的腿数 ÷ 2

**本质**：二元一次方程组 `{x+y=头数, 2x+4y=腿数}` 的算术解法。

**鸡兔同笼变体**：硬币问题（1元/5角）、答题得分（对加分/错扣分）、运输损坏（完好/破损）。

### 经典例题

**例7 · 盈亏问题**
小朋友分苹果，每人5个多10个，每人7个少6个。几人几个苹果？

> **解**  
> 一盈一亏：(10+6)÷(7−5) = 16÷2 = **8人**  
> 苹果 = 8×5+10 = **50个**（验证：8×7−6=50 ✓）

**例8 · 鸡兔同笼**
鸡兔同笼，35头94脚。鸡兔各几只？

> **解（假设法）**  
> 假设全鸡：35×2=70条腿，比实际少 94−70=24条  
> 每兔比鸡多2条 → 兔=24÷2=**12只**，鸡=35−12=**23只**

**例9 · 年龄问题**
父亲40岁，儿子10岁。几年后父亲年龄是儿子的3倍？

> **解**  
> 年龄差=30岁（永不变）  
> (40+x) = 3(10+x) → 40+x = 30+3x → 10=2x → **x=5年后**  
> 验证：父45，子15，45=3×15 ✓

## 四、平均数模型

**统一公式**：`平均数 = 总和 ÷ 个数`

### 4.1 算术平均

最基础的版本。

### 4.2 加权平均

```
加权平均 = (值₁×权₁ + 值₂×权₂ + ...) ÷ (权₁ + 权₂ + ...)
```

浓度混合本质就是加权平均。

### 4.3 移多补少

```
移动量 = 相差数 ÷ n
```

两组数量不同的东西，从一组移若干到另一组使相等：
- 每组内部移：移动量 = 相差数 ÷ 2
- 涉及多组：具体分析

### 经典例题

**例10 · 加权平均**
小明前3次测验平均85分，后2次平均91分。5次总平均分？

> **解**  
> 总平均 = (85×3+91×2)÷5 = (255+182)÷5 = 437÷5 = **87.4分**

## 五、归一 / 归总模型（正反比例）

### 5.1 归一问题

先算出**单一量**（一份是多少），再求其他。

```
一份量 = 总量 ÷ 份数
目标量 = 一份量 × 目标份数
```

### 5.2 归总问题

先算出**总量**，再求份数或每份量。

```
总量 = 每份量 × 份数
目标份数 = 总量 ÷ 新每份量
```

### 5.3 正比例 / 反比例

| 关系 | 特征 | 解法 |
|------|------|------|
| 正比例 | y/x = k（商一定） | 被除数÷商=除数 |
| 反比例 | xy = k（积一定） | 积不变列方程 |

**小学判断口诀**："商一定正比，积一定反比"

### 经典例题

**例11 · 归一**
3台机器4小时加工120个零件。5台机器6小时加工多少个？

> **解**  
> 1台1小时：120÷3÷4 = 10个  
> 5台6小时：10×5×6 = **300个**

**例12 · 反比例**
一批零件，每天20个需15天完成。如果12天完成，每天做多少个？

> **解**  
> 总量 = 20×15 = 300个  
> 每天量 = 300÷12 = **25个**（积一定：20×15 = x×12）

## 六、植树模型（间隔问题）

**统一公式**：`棵数与段数的关系取决于两端`

| 情况 | 公式 |
|------|------|
| 两端都种 | 棵数 = 段数 + 1 |
| 两端都不种 | 棵数 = 段数 − 1 |
| 只种一端（环形） | 棵数 = 段数 |
| 封闭图形 | 棵数 = 段数 |

**变形**：锯木头（锯的次数=段数−1）、爬楼梯（爬到n层=n−1层楼梯）、敲钟（间隔数=响数−1）。

### 经典例题

**例13 · 植树 + 爬楼**
(1) 路长200米，每5米种一棵（两端都种），种几棵？  
(2) 从1楼到3楼用30秒，到7楼需多少秒？（速度不变）

> **解**  
> (1) 棵数 = 200÷5+1 = **41棵**  
> (2) 1→3楼爬了2层，每层15秒。1→7楼爬6层，6×15 = **90秒**

## 七、周期与数列模型

### 7.1 周期问题

```
第n个 = 尾数 = n ÷ 周期 → 看余数对应第几个
组数 = n ÷ 周期 → 整组×每组个数 + 余数处理
```

### 7.2 等差数列

| 公式 | 表达式 |
|------|--------|
| 第 n 项 | a₁ + (n−1)d |
| 项数 n | (末项 − 首项) ÷ 公差 + 1 |
| 求和 | (首项 + 末项) × 项数 ÷ 2 |
| 中间项 | (首项 + 末项) ÷ 2 |

**常见应用**：堆木头/钢管（梯形公式求总数）、页码问题（1~n 用了多少个数字）。

### 7.3 页码与数字问题

| 范围 | 每个页码位数 | 该段总位数 |
|------|-------------|-----------|
| 1~9 | 1位 | 9 |
| 10~99 | 2位 | 180 |
| 100~999 | 3位 | 2700 |

### 经典例题

**例14 · 等差数列求和**
1+2+3+...+100 = ？

> **解**  
> (1+100)×100÷2 = **5050**

**例15 · 周期**
2024年元旦是星期一，2024年国庆节（10月1日）是星期几？

> **解**  
> 1.1→10.1 天数：31×5（1,3,5,7,8月）+ 30×3（4,6,9月）+ 29（2月）= 274天  
> 274÷7 = 39周余1天 → 星期一+1 = **星期二**

## 八、组合计数模型

### 8.1 加法原理与乘法原理

| 原理 | 特征 | 运算 |
|------|------|------|
| 加法原理 | 分类（选一类就行） | 各类加 |
| 乘法原理 | 分步（每步都要做） | 各步乘 |

### 8.2 容斥原理

```
|A∪B| = |A| + |B| − |A∩B|
|A∪B∪C| = |A|+|B|+|C| − |A∩B|−|B∩C|−|A∩C| + |A∩B∩C|
```

### 8.3 抽屉原理（鸽巢原理）

```
n+1 个物体放入 n 个抽屉 → 至少一个抽屉有 ≥2 个
m 个物体放入 n 个抽屉 → 至少一个抽屉有 ≥⌈m/n⌉ 个
```

**解题关键**：构造"抽屉"——把什么当作分类依据。

### 经典例题

**例16 · 容斥**
某班50人，喜欢数学的35人，喜欢语文的30人，两科都喜欢20人。两科都不喜欢？

> **解**  
> 至少喜欢一科 = 35+30−20 = 45人  
> 都不喜欢 = 50−45 = **5人**

**例17 · 抽屉原理**
任意13人中，至少几人生日在同一月？

> **解**  
> 13÷12 = 1余1 → ⌈13/12⌉ = **至少2人**同月出生

## 九、还原模型（逆向推理）

**特征**：知道最终结果，倒推初始状态。

**方法**：从最后一步开始，每步做逆运算。
```
加 → 减    乘 → 除    增长 → 减少
```

**工具**：画流程图或线段图，正向写操作，倒过来推算。

### 经典例题

**例18 · 还原**
一个数，加5，乘3，减6，除以2，得15。原数是多少？

> **解（倒推）**  
> 15×2=30 → 30+6=36 → 36÷3=12 → 12−5=**7**  
> 验证：7→加5→12→乘3→36→减6→30→除2→15 ✓

## 十、初中升级：方程与函数

以上所有小学奥数模型，初中统一升级为：

| 小学方法 | 初中升级 |
|----------|----------|
| 假设法（鸡兔同笼） | 二元一次方程组 |
| 盈亏公式 | 一元一次方程 |
| 量率对应 | 一元一次方程 |
| 比例关系 | 分式方程 / 正反比例函数 |
| 面积计算 | 二次方程 / 二次函数最值 |

### 初中新增典型题型

| 题型 | 数学模型 | 关键点 |
|------|----------|--------|
| 增长率问题 | a(1±x)ⁿ = b | 年均增长率/降低率 |
| 方案选择 | 一次函数/不等式比较 | 列两方案表达式，找临界点 |
| 最大利润 | 二次函数最值 | 利润=(售价−成本)×销量，求顶点 |
| 几何面积 | 二次方程 | 周长固定求最大面积 |
| 函数图像应用 | 读图求解析式 | 一次函数：找两点的k和b |
| 统计概率 | 加权平均/树状图 | 平均数、中位数、方差 |

### 经典例题

**例19 · 增长率**
某厂产值连续两年同比增长相同，从100万增至144万。求年增长率。

> **解**  
> 100(1+x)² = 144 → (1+x)² = 1.44 → 1+x = 1.2 → **x = 20%**

**例20 · 最大利润**
进价40元，售价x元时日销量为(120−x)件。定价多少时日利润最大？

> **解**  
> 日利润 y = (x−40)(120−x) = −x²+160x−4800  
> = −(x²−160x+4800) = −[(x−80)²−1600] = −(x−80)²+1600  
> 当 x=80 时，y_max = **1600元**

## 实战练习（25题·混合题型）

> 每题标注所属模型，先独立做，再对答案。

### 基础组（1-10题）

**1.** 🟢 甲速6km/h，乙速4km/h，从A、B相向而行，3h相遇。AB距离？【速率叠加-相遇】

**2.** 🟢 鸡兔同笼，共20头、56脚。鸡兔各几只？【总量守恒-鸡兔同笼】

**3.** 🟢 一条路长120m，两旁从头到尾每隔4m种一棵树。共种几棵？【植树模型】

**4.** 🟢 40%盐水300g，加水后浓度变为24%。加了多少克水？【比例不变-浓度】

**5.** 🟢 进价80元的商品按25%利润率定价出售，售价多少？利润多少？【比例不变-利润】

**6.** 🟢 4个工人6天修路240米。5个工人8天修多少米？【归一归总】

**7.** 🟢 一个数除以5，加8，乘3，得39。原数是多少？【还原模型】

**8.** 🟢 小明前4次数学成绩平均88分，第5次考了96分。5次平均分？【平均数】

**9.** 🟢 2025年6月1日是星期日，6月30日是星期几？【周期】

**10.** 🟢 两筐苹果共60个。从甲筐拿10个到乙筐，两筐一样多。原来各有多少？【总量守恒-和差】

### 进阶组（11-20题）

**11.** 🟡 一水池，进水管单独5h注满，排水管单独8h排空。两管齐开，几小时注满？【速率叠加-动态总量】

**12.** 🟡 一片草地，24头牛6天吃完，21头牛8天吃完。18头牛几天吃完？【速率叠加-牛吃草】

**13.** 🟡 父亲今年42岁，儿子12岁。几年前父亲年龄是儿子的6倍？【总量守恒-年龄】

**14.** 🟡 幼儿园分糖果，每人6颗多14颗，每人8颗正好分完。有多少个小朋友？【总量守恒-盈亏】

**15.** 🟡 35%盐水和15%盐水以什么质量比混合，得到25%盐水？【比例不变-浓度·十字交叉】

**16.** 🟡 某班有46人，会打篮球的28人，会踢足球的25人，两种都会的12人。两种都不会的有几人？【组合计数-容斥】

**17.** 🟡 把51个球放入5个抽屉，至少有一个抽屉不少于几个球？【组合计数-抽屉原理】

**18.** 🟡 等差数列：第3项为12，第7项为24。求第20项。【数列】

**19.** 🟡 一列火车长200m，速度20m/s，通过一座800m的桥，需要多少秒？【速率叠加-火车过桥】

**20.** 🟡 一本书80页，第一天看了1/4，第二天看了剩下的3/5。还剩下多少页没看？【比例不变-分数】

### 挑战组（21-25题）

**21.** 🔴 甲速比乙速快2km/h，甲乙从A、B相向而行，相遇时甲比乙多走12km，AB=60km。求甲速。【速率叠加-相遇·综合】

**22.** 🔴 13%盐水与27%盐水混合后，再加上200g水，得到600g浓度11%的盐水。原来两种盐水各用了多少克？【比例不变-浓度·多步混合】

**23.** 🔴 某商品按原价八折出售亏本32元，按九折出售则可盈利26元。进价多少元？【比例不变-利润·进阶】

**24.** 🔴 有一池水，开A管5h注满，开B管8h注满，开C管10h排空。三管齐开，几小时注满？【速率叠加-多管综合】

**25.** 🔴 某地居民用水：不超过20吨单价2元，超过20吨部分单价3元。王奶奶家上月水费55元，用水多少吨？【初中-分段计费·方案选择】

## 教学建议

1. **小学中低年级**：线段图是万能工具，先练画图再列式
2. **小学高年级**：逐步过渡到设未知数（方程思想的萌芽）
3. **小升初衔接**：把鸡兔同笼→方程组、盈亏→方程，体会算法的统一
4. **初中**：所有应用题本质是"找等量关系→列方程→解方程"

> **对学生说**：不用背几十种题型，记住——看到"变化"找速率，看到"混合"找守恒，看到"分配"找总和。剩下的就是加减乘除。
