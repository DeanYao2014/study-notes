# 一元二次方程 · 章节总结

> 八下 / 九上 | 浙教版 · 因式分解的直接应用

---

## 一、核心定义

\[
\boxed{ax^2 + bx + c = 0 \quad (a \neq 0)}
\]

| 项 | 系数 | 例：\(2x^2 - 3x + 1 = 0\) |
|------|:--:|------|
| 二次项 \(ax^2\) | \(a\) | \(a=2\) |
| 一次项 \(bx\) | \(b\) | \(b=-3\) |
| 常数项 \(c\) | \(c\) | \(c=1\) |

> ⚠️ \(a \neq 0\) 是铁律，否则退化为一元一次方程。

**三种退化形式（考试必考）：**

| 类型 | 形式 | 解法 |
|------|------|------|
| \(b=0\)（缺一次项） | \(ax^2 + c = 0\) | 直接开平方 |
| \(c=0\)（缺常数项） | \(ax^2 + bx = 0\) | 提公因式 → 因式分解 |
| \(b=c=0\) | \(ax^2 = 0\) | \(x=0\) |

---

## 二、四种解法

### 解法一：直接开平方法 ⭐

> 适用于无一次项（\(b=0\)）或已配成 \((x+m)^2 = k\) 的形式

\[
\boxed{x^2 = k \;\Longrightarrow\; x = \pm\sqrt{k} \quad (k \geq 0)}
\]

| 例题 | 解 |
|------|------|
| \(x^2 = 16\) | \(x = \pm 4\) |
| \((x-3)^2 = 25\) | \(x-3 = \pm 5 \;\rightarrow\; x = 8 \text{ 或 } x = -2\) |
| \(x^2 = -9\) | 无实数解 |

---

### 解法二：因式分解法 ⭐⭐⭐

> 适用于左边能分解成两个一次因式，右边 = 0

\[
\boxed{(mx+n)(px+q) = 0 \;\Longrightarrow\; mx+n=0 \;\text{ 或 }\; px+q=0}
\]

> 🔥 因式分解的终极用途就在这里！

| 类型 | 方程 | 分解 | 根 |
|------|------|------|------|
| 提公因式 | \(x^2 - 5x = 0\) | \(x(x-5)=0\) | \(x=0\) 或 \(x=5\) |
| 平方差 | \(x^2 - 16 = 0\) | \((x+4)(x-4)=0\) | \(x=\pm 4\) |
| 十字相乘 | \(x^2 + 5x + 6 = 0\) | \((x+2)(x+3)=0\) | \(x=-2\) 或 \(x=-3\) |
| 十字（首系数≠1） | \(2x^2 - x - 3 = 0\) | \((2x-3)(x+1)=0\) | \(x=\frac{3}{2}\) 或 \(x=-1\) |

---

### 解法三：配方法 ⭐⭐

> 通用方法，也是公式法的推导基础

\[
\boxed{x^2 + px \;\longrightarrow\; \left(x + \frac{p}{2}\right)^2 - \left(\frac{p}{2}\right)^2}
\]

**标准步骤：**

| 步 | 操作 | 例：\(x^2 + 6x - 7 = 0\) |
|:--:|------|------|
| 1 | 移常数到右边 | \(x^2 + 6x = 7\) |
| 2 | 两边 \(+\left(\frac{b}{2}\right)^2\) | \(x^2 + 6x + 9 = 7 + 9\) |
| 3 | 左边写成完全平方 | \((x+3)^2 = 16\) |
| 4 | 开平方求解 | \(x+3 = \pm 4 \;\rightarrow\; x = 1,\; -7\) |

---

### 解法四：公式法 ⭐⭐⭐⭐⭐（万能）

> 任何一元二次方程代入即得

\[
\boxed{x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}}
\]

**推导：** 对 \(ax^2+bx+c=0\) 配方 → 移项 → 开方 → 移项，就得到这个公式。

例：\(2x^2 - 5x + 1 = 0\)

\[
a=2,\;b=-5,\;c=1 \;\rightarrow\; x = \frac{5 \pm \sqrt{25-8}}{4} = \frac{5 \pm \sqrt{17}}{4}
\]

---

### 四种解法的选择策略 🎯

```
拿到方程 → b=0？ → 直接开平方
         → 能因式分解？ → 因式分解法（快）
         → 配方或公式 → 系数简单用配方，复杂用公式
```

---

## 三、判别式 \(\Delta\) — 判断有几个根

\[
\boxed{\Delta = b^2 - 4ac}
\]

| \(\Delta\) | 根的情况 | 含义 |
|:---:|------|------|
| \(\Delta > 0\) | 两个**不等**实数根 | 穿 x 轴两点 |
| \(\Delta = 0\) | 两个**相等**实数根（重根） | 刚好切 x 轴 |
| \(\Delta < 0\) | 无实数根 | 不碰 x 轴 |

---

## 四、🟡 韦达定理（根与系数的关系）

> 对 \(ax^2+bx+c=0\)，当 \(\Delta \geq 0\)

\[
\boxed{x_1 + x_2 = -\frac{b}{a}} \qquad
\boxed{x_1 x_2 = \frac{c}{a}}
\]

### 常用变形（不用解方程，直接算对称式）

| 求 | 用 \(S = x_1+x_2,\; P = x_1x_2\) 表达 |
|------|------|
| \(x_1^2 + x_2^2\) | \(S^2 - 2P\) |
| \(\frac{1}{x_1} + \frac{1}{x_2}\) | \(\frac{S}{P}\) |
| \((x_1 - x_2)^2\) | \(S^2 - 4P\) |
| \(\lVert x_1 - x_2\rVert\) | \(\frac{\sqrt{\Delta}}{\lVert a\rVert}\) |

### 构造方程

> 以 \(p, q\) 为两根的方程：\(x^2 - (p+q)x + pq = 0\)

---

## 五、🟡 应用题模型

| 模型 | 关系式 | 典型设未知数 |
|------|--------|------|
| 增长率 | \(a(1+x)^2 = b\) | 设增长率为 \(x\) |
| 矩形面积 | \(x(\frac{L}{2}-x) = S\) | 设宽为 \(x\) |
| 连续整数 | \(x(x\pm1) = 积\) 或 \(x(x\pm2) = 积\) | 设较小数为 \(x\) |
| 直角三角形 | \(a^2 + b^2 = c^2\)（勾股） | 设最短边 |

---

## 六、常考题型

### 题型1：方程判定

> \((m-2)x^2 + mx + 1 = 0\) 是一元二次方程 → \(m \neq 2\)

### 题型2：解方程（四种方法各选）

> 先判断特征再选方法，别上来就套公式

### 题型3：根的情况讨论 🔴

> "方程有两个不等实根" → \(\Delta > 0\)，列不等式求参数范围

### 题型4：韦达定理求值

> 已知 \(x^2 - 6x + 4 = 0\)，不解方程，求 \(x_1^2 + x_2^2 = 36 - 8 = 28\)

### 题型5："公共根"问题 🔴

> 两方程有公共根 → 设公共根为 \(t\)，代入两方程联立消 \(t^2\)

## 七、必背公式卡片

| # | 公式 | 用途 |
|---|------|------|
| 1 | \(x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}\) | 求根公式（万能，先写 \(\Delta\)） |
| 2 | \(\Delta = b^2 - 4ac\) | 判断根个数 |
| 3 | \(x_1 + x_2 = -\frac{b}{a}\) | 韦达—和 |
| 4 | \(x_1x_2 = \frac{c}{a}\) | 韦达—积 |
| 5 | \(x^2 - (S)x + (P) = 0\) | 已知和 \(S\)、积 \(P\)，构造方程 |

## 八、易错点

1. **忘写 \(a \neq 0\)** — 含参方程判定时，先看二次项系数
2. **开平方忘 ±** — \(x^2 = 9 \rightarrow x = \pm 3\)，不是只写 3
3. **因式分解不等号搞反** — \((x+2)(x-3)=0 \rightarrow x=-2, 3\)，不是 \(x=2,-3\)
4. **公式法 \(b\) 的符号代错** — 公式是 \(-b\)，\(b=-5\) 时 \(-(-5)=+5\)
5. **韦达定理分母记成 \(a\)** — 和是 \(-b/a\)（有负号），积是 \(c/a\)（无负号）
6. **\(\Delta<0\) 还接着算** — 先判 \(\Delta\)，无实根就直接写"无解"
