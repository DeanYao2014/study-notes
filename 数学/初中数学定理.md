## 一、代数

### 1.1 实数与运算

| # | 定理/规则 | 说明 |
|---|------|------|
| 1 | **绝对值**：`\|a\| ≥ 0`；`\|a\| = a (a≥0)`，`\|a\| = -a (a<0)` | 非负性 |
| 2 | **相反数**：`a + (-a) = 0` | 和为 0 互反 |
| 3 | **倒数**：`a × (1/a) = 1`（a ≠ 0） | 积为 1 互倒 |
| 4 | **科学记数法**：`a × 10ⁿ`，1 ≤ \|a\| < 10 | n 是整数 |

**运算律**：

| 律 | 公式 |
|------|------|
| 交换律 | `a + b = b + a`，`ab = ba` |
| 结合律 | `(a + b) + c = a + (b + c)`，`(ab)c = a(bc)` |
| 分配律 | `a(b + c) = ab + ac` |

**乘方**：

| # | 公式 | 条件 |
|---|------|------|
| 1 | `aᵐ × aⁿ = aᵐ⁺ⁿ` | m,n 正整数 |
| 2 | `aᵐ ÷ aⁿ = aᵐ⁻ⁿ` | a ≠ 0, m>n |
| 3 | `(aᵐ)ⁿ = aᵐⁿ` | |
| 4 | `(ab)ⁿ = aⁿbⁿ` | |
| 5 | `a⁰ = 1` | a ≠ 0 |
| 6 | `a⁻ⁿ = 1/aⁿ` | a ≠ 0 |

**平方根与立方根**：

| # | 定义 | 公式 |
|---|------|------|
| 1 | 平方根：若 x² = a，则 x = ±√a | `(√a)² = a`（a ≥ 0） |
| 2 | 算术平方根：√a ≥ 0 | `√(a²) = \|a\|` |
| 3 | 立方根：若 x³ = a，则 x = ∛a | `(∛a)³ = a`（a 任意） |

### 1.2 整式

**基本概念**：

| 概念 | 定义 | 例 |
|------|------|------|
| 单项式 | 数或字母的积，单独一个数/字母也算 | `3x²y`, `-5`, `a` |
| 多项式 | 几个单项式的和 | `x² + 2x - 3` |
| 整式 | 单项式和多项式的统称（分母不含字母，根号内不含字母） | |
| 同类项 | 字母相同且指数也相同的项 | `3x²` 与 `-5x²` |
| 次数 | 单项式中所有字母指数之和；多项式中最高次项的次数 | |

**幂的运算**：同上 1.1 乘方公式。

**乘法公式（必背！）**：

| # | 公式 | 名称 |
|---|------|------|
| 1 | `(a + b)² = a² + 2ab + b²` | 完全平方公式（和） |
| 2 | `(a - b)² = a² - 2ab + b²` | 完全平方公式（差） |
| 3 | `(a + b)(a - b) = a² - b²` | 平方差公式 |
| 4 | `(x + a)(x + b) = x² + (a+b)x + ab` | 十字相乘展开 |
| 5 | `(a + b + c)² = a² + b² + c² + 2ab + 2bc + 2ca` | 三项完全平方 |

### 1.3 因式分解

**定义**：把一个多项式化成几个整式的积的形式。

**方法体系**：

| 步骤 | 方法 | 公式/说明 |
|------|------|------|
| 一提 | 提公因式 | `ma + mb + mc = m(a + b + c)` |
| 二套 | 平方差 | `a² - b² = (a + b)(a - b)` |
| 二套 | 完全平方 | `a² ± 2ab + b² = (a ± b)²` |
| 三十字 | 十字相乘 | `x² + (p+q)x + pq = (x + p)(x + q)` |
| 四分组 | 分组分解 | `ma + mb + na + nb = (m + n)(a + b)` |

**拓展公式**（竞赛）：

| # | 公式 |
|---|------|
| 1 | `a³ + b³ = (a + b)(a² - ab + b²)` |
| 2 | `a³ - b³ = (a - b)(a² + ab + b²)` |
| 3 | `(a + b)³ = a³ + 3a²b + 3ab² + b³` |
| 4 | `(a + b + c)(a² + b² + c² - ab - bc - ca) = a³ + b³ + c³ - 3abc` |

### 1.4 分式

| # | 定理/法则 | 内容 |
|---|------|------|
| 1 | 分式定义 | 形如 A/B（B ≠ 0，B 含字母）的式子 |
| 2 | 基本性质 | `A/B = (A×C)/(B×C)`，`A/B = (A÷C)/(B÷C)`（C ≠ 0） |
| 3 | 约分 | 分子分母同除以公因式 |
| 4 | 通分 | 化为同分母：先找最简公分母 |
| 5 | 加减法 | 同分母：`a/c ± b/c = (a±b)/c`；异分母先通分 |
| 6 | 乘法 | `a/b × c/d = ac/(bd)` |
| 7 | 除法 | `a/b ÷ c/d = a/b × d/c`（乘倒数） |
| 8 | 乘方 | `(a/b)ⁿ = aⁿ/bⁿ` |
| 9 | 分式值为 0 | 分子 = 0 且分母 ≠ 0 |

### 1.8 一元二次方程

| # | 定理/方法 | 内容 |
|---|------|------|
| 1 | 一般形式 | `ax² + bx + c = 0`（a ≠ 0）|
| 2 | 开平方法 | `x² = p` → `x = ±√p`（p ≥ 0） |
| 3 | **配方法** | 化 `x² + px + q = 0` 为 `(x + p/2)² = (p/2)² - q` |
| 4 | **公式法** | `x = (-b ± √(b²-4ac)) / (2a)` |
| 5 | 因式分解法 | 左边分解 → 每因式 = 0 |
| 6 | **判别式** `Δ = b² - 4ac` | Δ > 0：两不等实根；Δ = 0：两相等实根；Δ < 0：无实根 |
| 7 | **韦达定理** | `x₁ + x₂ = -b/a`，`x₁·x₂ = c/a` |
| 8 | 根与系数倒推 | 已知两根 x₁,x₂ → 方程为 `x² - (x₁+x₂)x + x₁x₂ = 0` |

### 1.10 函数

**一次函数** `y = kx + b`（k ≠ 0）：

| # | 性质 | 内容 |
|---|------|------|
| 1 | k > 0 | 递增，直线向上倾斜 |
| 2 | k < 0 | 递减，直线向下倾斜 |
| 3 | b > 0 | 交 y 轴正半轴 |
| 4 | b = 0 | 过原点（正比例函数 y = kx） |
| 5 | b < 0 | 交 y 轴负半轴 |
| 6 | \|k\| 越大 | 直线越陡 |
| 7 | 两点定直线 | 两个点确定唯一一条一次函数 |

**二次函数** `y = ax² + bx + c`（a ≠ 0）：

| # | 性质 | 公式/内容 |
|---|------|------|
| 1 | 开口方向 | a > 0 开口向上；a < 0 开口向下 |
| 2 | 对称轴 | `x = -b/(2a)` |
| 3 | 顶点坐标 | `(-b/(2a), (4ac-b²)/(4a))` |
| 4 | 顶点式 | `y = a(x - h)² + k`，顶点 `(h, k)` |
| 5 | 交点式 | `y = a(x - x₁)(x - x₂)` |
| 6 | 与 x 轴交点 | 即 ax² + bx + c = 0 的根，由 Δ 决定 |
| 7 | \|a\| 越大 | 抛物线越窄 |

**反比例函数** `y = k/x`（k ≠ 0）：

| # | 性质 | 内容 |
|---|------|------|
| 1 | k > 0 | 双曲线在一、三象限，递减 |
| 2 | k < 0 | 双曲线在二、四象限，递增 |
| 3 | \|k\| | 双曲线上任一点横纵坐标乘积 = \|k\| |
| 4 | 渐近线 | x 轴和 y 轴（永远不会碰到轴） |
| 5 | 对称性 | 关于原点中心对称，关于 y = ±x 轴对称 |

### 2.3 三角形

**三角形基础**：

| # | 定理 | 内容 |
|---|------|------|
| 1 | **三角形内角和** | `∠A + ∠B + ∠C = 180°` |
| 2 | 外角定理 | 三角形一个外角 = 不相邻两内角之和 |
| 3 | 外角和 | 三角形外角和 = 360° |
| 4 | **三边关系** | 两边之和 > 第三边，两边之差 < 第三边 |
| 5 | 大边对大角，大角对大边 | |
| 6 | 稳定性 | 三角形具有稳定性（三边确定则形状唯一） |

**三角形中的重要线段**：

| 线段 | 定义 | 性质 |
|------|------|------|
| 中线 | 连接顶点与对边中点 | 三条中线交于一点（重心）；重心分中线 2:1 |
| 高线 | 顶点向对边作垂线 | 三条高交于一点（垂心） |
| 角平分线 | 平分内角 | 三条角平分线交于一点（内心—内切圆圆心） |
| 中位线 | 连接两边中点 | **平行第三边且等于第三边的一半** |

**特殊三角形**：

| # | 类型 | 性质 |
|---|------|------|
| 1 | **等腰三角形** | **等边对等角**；三线合一（顶角平分线=底边中线=底边高线） |
| 2 | 等腰三角判定 | **等角对等边** |
| 3 | 等边三角形 | 三角都 = 60°；三线都合一 |
| 4 | 等边三角判定 | ①三边相等 ②三角相等 ③一内角 60° 的等腰三角形 |
| 5 | **直角三角形** | 两锐角互余 |
| 6 | 30° 所对直角边 | 30° 所对直角边 = **斜边的一半** |
| 7 | 斜边中线 | 斜边上的中线 = **斜边的一半** |

### 2.4 全等三角形（八年级上）

**定义**：能够完全重合的两个三角形。

**五大判定**：

| # | 判定 | 条件 |
|---|------|------|
| 1 | **SSS** | 三边分别相等 |
| 2 | **SAS** | 两边及其夹角分别相等 |
| 3 | **ASA** | 两角及其夹边分别相等 |
| 4 | **AAS** | 两角及一对边分别相等 |
| 5 | **HL**（仅直角三角形） | 斜边和一条直角边分别相等 |

**全等性质**：对应边相等、对应角相等、对应线段（中线/高/角平分线）相等。

### 2.10 圆（九年级上）

**圆心角与圆周角**：

**与圆有关的位置关系**：

## 三、统计与概率

### 3.1 统计

| # | 概念 | 定义/公式 |
|---|------|------|
| 1 | 平均数 | `x̄ = (x₁ + x₂ + ... + xₙ)/n` |
| 2 | 加权平均数 | `x̄ = (f₁x₁ + f₂x₂ + ... + fₙxₙ) / (f₁ + f₂ + ... + fₙ)` |
| 3 | **中位数** | 排序后中间位置的数（偶数个则中间两数平均） |
| 4 | **众数** | 出现次数最多的数（可有多个或没有） |
| 5 | 极差 | 最大值 − 最小值 |
| 6 | **方差** | `s² = [(x₁-x̄)² + (x₂-x̄)² + ... + (xₙ-x̄)²] / n` |
| 7 | 标准差 | `s = √s²` |
| 8 | 方差公式 2 | `s² = (x₁² + x₂² + ... + xₙ²)/n - x̄²` |
| 9 | 频数 = 频率 × 总数 | 频率 = 频数/总数 |

### 3.2 概率

| # | 概念 | 定义/公式 |
|---|------|------|
| 1 | 概率定义 | `P(A) = 事件 A 包含的结果数 / 所有等可能结果总数` |
| 2 | 概率范围 | `0 ≤ P(A) ≤ 1`（0 = 不可能，1 = 必然） |
| 3 | 对立事件 | `P(非A) = 1 - P(A)` |
| 4 | 互斥事件 | `P(A∪B) = P(A) + P(B)`（A,B 不会同时发生） |
| 5 | 独立事件 | `P(AB) = P(A)·P(B)`（A,B 互不影响） |
| 6 | 列表法/树状图 | 求概率的两大工具 |
