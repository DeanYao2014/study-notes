## Day 1 · 坐标系 + 函数概念（35 min）

### 为什么要学？

> 孩子可能会问："坐标是什么？能干嘛？"
>
> **答**：手机导航、外卖地址、电影院的座位号——全都是坐标。你给朋友发定位，就是在发一个坐标 `(经度, 纬度)`。"函数"更厉害，它是描述世界上一切规律的通用语言：
> - 你长高了 → 身高是年龄的函数
> - 空调开得越久 → 电费是时间的函数
> - 西瓜越重越贵 → 价格是重量的函数
>
> **今天的任务**：学会"画地图"（坐标系），然后理解"什么叫函数"。

---

### 1.1 坐标系：把平面变成"地图"（10 min）

> 告诉孩子：**坐标系 = 给平面上每个点起一个名字（坐标）**。就像每家有一个门牌号。

```
              y 轴 (纵轴)
                ↑
            Q2  |  Q1       ← 第一象限 (+,+)
        (−,+)  |  (+,+)
                |
    —————————————+————————————→  x 轴 (横轴)
                | 原点 O(0,0)
            Q3  |  Q4
        (−,−)  |  (+,−)
```

| 核心规则 | 说明 |
|------|------|
| 坐标写法 | `(x, y)` — **先横后纵**，横坐标在前，纵坐标在后 |
| 点在象限 | 看 x, y 的正负号 |
| 原点 | `(0, 0)`，x 轴和 y 轴的交点 |

### 1.2 点的对称与平移（5 min）

| 操作 | 规则 | 例：(2, 3) |
|------|------|------|
| 关于 x 轴对称 | y 变号 | (2, −3) |
| 关于 y 轴对称 | x 变号 | (−2, 3) |
| 向上/下平移 | 只改 y | 上移 3 → (2, 6) |
| 向左/右平移 | 只改 x | 右移 4 → (6, 3) |

### 1.3 什么是函数？（10 min）

> **核心定义**：对于 x 的每一个值，y 有**唯一确定**的值与之对应。
>
> 换句话说：**一个 x 只能对应一个 y**（一个 y 可以对应多个 x）。

```
✓ 是函数：y = 2x       每个 x → 唯一 y
✓ 是函数：y = x²       x=2→y=4, x=−2→y=4（一 y 多 x，OK）
✗ 不是函数：x²+y²=1   x=0 时 y=±1（一个 x 对应两个 y，不行！）

识图口诀：画一条竖线从左滑到右——
  竖线和图像永远最多 1 个交点 → 函数
  竖线和图像有 2 个及以上交点 → 不是函数
```

三种表示法：

| 方式 | 例子 | 什么时候好用 |
|------|------|------|
| 列表法 | x: 1,2,3; y: 3,5,7 | 数据少、对应清晰 |
| 解析式法 | y = 2x + 1 | 通用、方便计算 |
| 图像法 | 坐标系中的直线 | **一眼看趋势** |

> 自变量 x，因变量 y — y 的值"因 x 而变"。

### 1.4 自变量的取值范围（5 min）

| 场景 | 限制条件 | 例 |
|------|------|------|
| 分母 | 分母 ≠ 0 | y = 1/(x−2) → x ≠ 2 |
| 根号 | 被开方数 ≥ 0 | y = √(x+3) → x ≥ −3 |
| 实际意义 | 根据题意 | 人数 → 非负整数 |

### Day 1 练习（5 min · 口头检查）

```
1. 点 A(−5, 3) 在第几象限？关于 x 轴对称的点是？
   （第二象限；(−5, −3)）

2. 圆的方程 x² + y² = 4，y 是 x 的函数吗？
   （不是，一个 x 可对应两个 y）

3. 写出"每个学生对应一个学号"中，谁是自变量？
   （学生是自变量 x，学号是函数值 y）
```

## Day 2 · 从正比例函数到一次函数（35 min）

### 为什么要学？

> 生活中最简单的两个量之间的关系是什么？**正比**。
>
> - 买 3 个苹果，每个 5 元 → 总价 = 5 × 个数（典型的 y = kx）
> - 时速 60 公里，开 2 小时 → 路程 = 60 × 时间（又是 y = kx）
>
> 但现实不总是"从零开始"。出租车有起步价、电费有基础档、工资有底薪——这些都得加上一个"起步量"。这就从 y = kx 变成了 y = kx + b。
>
> **今天的任务**：先搞懂最简单的 y = kx，再往前多走一步，把"底薪/起步价"加进去，得到一次函数。

---

### 2.1 正比例函数 y = kx（15 min）

> **定义**：形如 `y = kx`（k ≠ 0）的函数。图像是**过原点 (0, 0)** 的直线。

**k 的含义**：x 每增加 1，y 就增加 k。**k 就是"步长"**。

```
k = 2：每走 1 步，上升 2 格。图像 ↗ 过一三象限
k = −3：每走 1 步，下降 3 格。图像 ↘ 过二四象限
```

| k 的符号 | 图像方向 | 经过象限 | 增减性 |
|:--:|:--:|------|------|
| k > 0 | ↗ | 一、三 | y 随 x 增大而增大 |
| k < 0 | ↘ | 二、四 | y 随 x 增大而减小 |
| \|k\| 越大 | 越陡 | — | 变化越快 |
| \|k\| 越小 | 越平 | — | 变化越慢 |

**画图**：过原点，再找一点。如 y = 3x：过 (0,0)，取 x=1 → y=3，(1,3)，连两点成直线。

**求解析式**：知道一点（非原点）→ 代入求 k。

**例**：正比例函数过 (2, 6)，求表达式。→ 6 = k×2 → k=3 → y = 3x。

### 2.2 一次函数 y = kx + b（15 min）

> **定义**：形如 `y = kx + b`（k ≠ 0）。图像是**不过原点**的直线。
>
> **本质**：`y = kx + b` = **正比例函数 y = kx 向上（b>0）或向下（b<0）平移 \|b\| 个单位**。

| 参数 | 叫什么 | 含义 | 控制什么 |
|:--:|------|------|------|
| k | 斜率 | 变化率（每步变多少） | 方向 + 坡度 |
| b | 截距 | 初始值（x=0 时的 y） | 线的高低位置 |

**找 k 和 b**：已知直线上两点 (x₁, y₁) 和 (x₂, y₂)

```
k = (y₂ − y₁) / (x₂ − x₁)     ← "高度差 ÷ 水平距离"
b = y₁ − kx₁                     ← 代入任意一点求 b
```

**例**：过 (1, 4) 和 (3, 10)

→ k = (10−4)/(3−1) = 3 → 代入 (1,4)：4 = 3×1 + b → b = 1 → y = 3x + 1

### 2.3 先判断是不是正比例（5 min）

```
y = 3x       → 是正比例（也是特殊的一次函数，b=0）
y = 2x − 5   → 是一次函数，不是正比例（b≠0）
y = 5        → 常数函数（k=0，不是一次函数）
y = 1/x      → 不是一次函数（x 在分母）
```

> 🔑 一次函数 = 自变量 x 的**最高次数 = 1** + x **不在分母、不在根号里**。

### Day 2 练习（5 min）

```
1. 正比例函数过点 (4, −12)，求 k。（k = −3）

2. 直线过 (2, 5) 和 (−1, −4)，求表达式。
   （k=(−4−5)/(−1−2)=3, b=5−6=−1 → y=3x−1）

3. 下列哪个是一次函数？
   y=3x² ✗（x 是二次）  y=1/x ✗（x 在分母）  y=−2x+7 ✓
```

## Day 3 · 一次函数的图像与性质（35 min）

### 为什么要学？

> 公式和图像就像中文和英文——说的是同一件事，只是表达方式不同。
>
> 老板说"月薪 = 3000 底薪 + 500 × 工作年限"，你可以写成 `y = 500x + 3000`，也可以画成一条向上走的直线。**图和公式，哪个直观就看哪个**。
>
> 今天要掌握的：拿到一个一次函数，脑中自动浮现一条直线——陡不陡？往上还是往下？从多高开始的？两条线会不会相交？
>
> **今天的任务**：把 k 和 b 变成直觉——k 是"每步变化"，b 是"从哪出发"。同时学会判断两条线是平行还是相交。

---

### 3.1 画一次函数的图（10 min）

> 一条直线只需要**两个点**就能确定。

```
方法一：取 x=0 和 y=0（截距法，不一定整数，但准）
方法二：任意取两个好算的 x 值

例：画 y = −x + 3
  x=0 → y=3：(0,3)
  y=0 → x=3：(3,0)
  描点 → 连线 → 得到一条 ↘ 的直线
```

### 3.2 k 和 b 分别控制什么（10 min）— 看四张图

```
k > 0, b > 0：  ↗ 交 y 轴正半轴    一次函数典型姿态
k > 0, b < 0：  ↗ 交 y 轴负半轴
k < 0, b > 0：  ↘ 交 y 轴正半轴
k < 0, b < 0：  ↘ 交 y 轴负半轴

关键结论：
  k > 0 → 图像 ↗（递增）   k < 0 → 图像 ↘（递减）
  b > 0 → 与 y 轴交于原点上方   b < 0 → 与 y 轴交于原点下方
```

### 3.3 两条直线的三种关系（10 min）

| 关系 | 条件 | 含义 |
|------|------|------|
| **平行** | `k₁ = k₂` 且 `b₁ ≠ b₂` | 方向相同，永不交叉 |
| **重合** | `k₁ = k₂` 且 `b₁ = b₂` | 同一条线 |
| **相交** | `k₁ ≠ k₂` | 在某一点交叉 |

**求交点**：联立两个解析式 → 解方程 → 得 x → 回代得 y。

**例**：y = 2x + 1 和 y = −x + 7

```
2x + 1 = −x + 7 → 3x = 6 → x = 2
y = 2×2+1 = 5
交点：(2, 5)
```

### 3.4 一次函数与一元一次方程（5 min）

> **一次函数 y = kx + b 的图像与 x 轴的交点 = 方程 kx + b = 0 的解。**

```
y = 2x − 4 与 x 轴交点：设 y=0 → 2x−4=0 → x=2
交点为 (2, 0)，方程的解就是 x=2。

一句话：令 y=0，得到的 x 就是交点的横坐标，就是方程的解。
```

### Day 3 练习（5 min）

```
1. 直线 y = 3x − 1 与 y = 3x + 5 平行吗？
   （平行。k 都 = 3，b 不同）

2. 判断直线性质，不画图：
   y = −2x + 4 → k=−2<0 递减，b=4>0 交 y 轴正半轴

3. y = 2x − 6 与 x 轴的交点坐标？
   （令 y=0: x=3 → (3, 0)）
```

## Day 4 · 一元一次不等式及其解法（35 min）

### 为什么要学？

> 方程告诉你"一个精确的点"——什么时候刚好相等。但生活中更多时候我们问的是"什么时候够？什么时候超过？什么时候不够？"
>
> - "卡里还有 50 元，每天花 12 元，能撑几天？" → 这是不等式：`50 − 12x ≥ 0`
> - "体重不能超过 60 公斤" → 不等式：`w ≤ 60`
> - "排名要进前 10" → 不等式：`r ≤ 10`
>
> 不等式就是**给生活设定边界条件**。它和方程的唯一区别就是：**乘除负数时要翻方向**——就这一个新东西。
>
> **今天的任务**：学会解不等式，掌握"翻方向"规则，能在数轴上画出解集。

---

### 4.1 不等式的基本概念（5 min）

| 符号 | 读法 | 含义 |
|:--:|------|------|
| > | 大于 | 严格大于 |
| < | 小于 | 严格小于 |
| ≥ | 大于等于 | 不小于 |
| ≤ | 小于等于 | 不大于 |

> **不等式的解**：使不等式成立的未知数的所有值（通常是**一个范围**，不是单个数字）。
>
> 对比：方程的解 → 一个数；不等式的解 → 一个范围。

### 4.2 不等式的三条基本性质（10 min · 核心！）

| 性质 | 内容 | 例 |
|------|------|------|
| 性质 1 | 两边同加/同减一个数，**不等号方向不变** | x−3>5 → x>8 |
| 性质 2 | 两边同乘/同除一个**正数**，不等号方向不变 | 2x>6 → x>3 |
| 性质 3 | 两边同乘/同除一个**负数**，不等号**方向改变**！ | −2x>6 → **x<−3** |

> ⚠ **性质 3 是最大的坑**：乘以/除以负数必须翻方向！这是不等式和方程唯一不同的地方。

```
讲解时强化：

  方程：2x = 6 → x = 3         −2x = 6 → x = −3（符号正常）
  不等式：2x > 6 → x > 3        −2x > 6 → x < −3（翻号！）

为什么翻号？直观理解：
  3 > 2  是对的
  两边乘 −1：−3 > −2  是错的！应该是 −3 < −2
  → 乘了负数，大小关系就反了
```

### 4.3 解一元一次不等式（10 min）

步骤和一元一次方程几乎一样，**唯一区别：乘除负数时翻号**。

**例 1**：`3x − 7 > 2x + 1`

```
3x − 7 > 2x + 1
3x − 2x > 1 + 7      （移项变号，不等号不动）
x > 8                  ← 解集
```

**例 2**：`5 − 2x ≥ 9`

```
5 − 2x ≥ 9
−2x ≥ 4               （5 移过去：9−5=4）
x ≤ −2                 ← 除以 −2，翻号！≥ → ≤
```

**例 3**（分数）：`(x+1)/3 − (x−2)/2 < 1`

```
两边乘 6：2(x+1) − 3(x−2) < 6
2x+2 − 3x+6 < 6
−x + 8 < 6
−x < −2
x > 2                  ← 除以 −1，翻号！< → >
```

### 4.4 不等式的解在数轴上表示（10 min）

> 告诉孩子：**数轴是表示不等式解集最直观的工具。**

```
x > 2：     ———o══════→       空心圈在 2，向右（2 不包含）
                2

x ≥ −1：    ———●══════→       实心点在 −1，向右（−1 包含）
               −1

x < 3：     ←══════o———       空心圈在 3，向左（3 不包含）
                    3

−2 < x ≤ 4： ———o══════●———   空心在 −2（不包含），实心在 4（包含）
               −2       4
```

| 符号 | 数轴标记 |
|:--:|:--:|
| > 或 < | **空心圈** ○（不含端点） |
| ≥ 或 ≤ | **实心点** ●（含端点） |

### Day 4 练习（5 min）

```
解下列不等式并在数轴上表示解集：

1. 2x + 3 > 7
   → 2x > 4 → x > 2（数轴：2 处空心向右）

2. 5 − 3x ≤ 11
   → −3x ≤ 6 → x ≥ −2（除以 −3，翻号！）（数轴：−2 处实心向右）

3. −4(x − 1) ≥ 8
   → −4x+4 ≥ 8 → −4x ≥ 4 → x ≤ −1（数轴：−1 处实心向左）
```

## Day 5 · 函数与不等式数形结合 + 实际应用（35 min）

### 为什么要学？

> 前 4 天分别学了坐标系、函数、不等式——看起来是三个东西，其实**是一回事**。
>
> 方程告诉你"什么时候两件事相等"，不等式告诉你"什么时候一个比另一个多/少"，函数图像让你**一眼看穿全部**。
>
> 今天你就能做到：看到 `2x − 4 > 0`，脑中直接浮现直线 y = 2x − 4，看它在 x 轴上方的那段，一秒读出答案 x > 2。这种"数形转换"才是初中数学真正有用的能力。
>
> 最后的实际应用题——套餐选择、出租车计价、阶梯水电费——这些考试必考，而且学完就能在生活中用上。
>
> **今天的任务**：打通函数和不等式，学会用图解题；做完 4 道应用模型，期末直接拿来用。

---

### 5.1 一图三用：方程、不等式、函数（10 min）

画一条直线 y = 2x − 4：

```
           y
           ↑
           |        /
           |       /   y = 2x−4
  y > 0    |      /
  区域     |     /
  ─────────+────/────→ x
           |   /
  y < 0    |  /
  区域     | /
           |/
           ● (2, 0)    ← 与 x 轴交点
           |
```

| 问题 | 答案 | 怎么看 |
|------|------|------|
| 方程 2x−4=0 | x=2 | 直线与 x 轴**交点**的横坐标 |
| 不等式 2x−4>0 | x>2 | 直线在 x 轴**上方**对应的 x 范围 |
| 不等式 2x−4<0 | x<2 | 直线在 x 轴**下方**对应的 x 范围 |

> 🎯 **告诉孩子**："以后解不等式，不用死记方向。画出 y=kx+b 的图，看 x 轴上方还是下方，直接读出答案。"

### 5.2 比较两个函数值的大小（5 min）

> 谁在上面谁就大。

```
画 y₁ = x + 2  和  y₂ = −x + 4

两线交于 (1, 3)
  x < 1 时：y₁ < y₂  （绿线在红线上方？看实际图判断）
  x = 1 时：y₁ = y₂
  x > 1 时：y₁ > y₂

总结：比较函数值 → 找交点 → 分区间看谁在上谁在下
```

### 5.3 实际应用题（15 min · 精选）

**题 1 · 方案选择**（必讲）

> 移动套餐 A：月租 20 元，通话 0.1 元/分钟。
> 移动套餐 B：月租 0 元，通话 0.3 元/分钟。
> 每月通话 x 分钟，选哪个划算？

```
A: y₁ = 0.1x + 20
B: y₂ = 0.3x

交点：0.1x+20 = 0.3x → 20 = 0.2x → x = 100 分钟

x < 100：y₁ > y₂ → B 便宜
x = 100：一样
x > 100：y₁ < y₂ → A 便宜

结论：打得少选 B（0 月租），打得多选 A（每分钟便宜）
```

**题 2 · 出租车**

> 起步价 10 元（含 3 公里），超出后 2 元/公里。
> (1) 写出 x>3 时费用 y 的表达式。
> (2) 坐 20 公里多少钱？
> (3) 交了 50 元，最多坐多少公里？

```
(1) y = 10 + 2(x−3) = 2x + 4（x > 3）
(2) x=20 → y = 2×20+4 = 44 元
(3) 50 = 2x+4 → 2x = 46 → x = 23 公里
```

**题 3 · 水箱放水**

> 水箱原有 200 升水，每分钟放出 6 升。
> (1) 写水量 V 与时间 t 的关系。
> (2) 什么时候剩 50 升？
> (3) 什么时候放完？

```
(1) V = 200 − 6t（t ≥ 0）
(2) 50 = 200−6t → 6t=150 → t=25 分钟
(3) 0 = 200−6t → 200=6t → t≈33.3 分钟
```

**题 4 · 阶梯水费**

> 每月 ≤ 15 吨：3 元/吨。
> 超出部分：5 元/吨。
> (1) 写 x > 15 时的水费表达式。
> (2) 用了 22 吨，交多少？

```
(1) y = 3×15 + 5(x−15) = 5x − 30（x > 15）
(2) x=22 → y = 5×22−30 = 80 元
```

### 5.4 5 天知识点汇总（5 min）

```
1. 坐标系：点 (x,y)，先横后纵，四个象限
2. 函数：一个 x 对应唯一 y
3. 正比例 y=kx：过原点的直线，k 是步长
4. 一次函数 y=kx+b：直线，k 管方向坡度，b 管高低
5. 两直线：k₁=k₂ 平行；k₁≠k₂ 相交
6. 一元一次不等式：解法同方程，但乘除负数翻方向
7. 数形结合：方程的解 = 与 x 轴交点；不等式解 = x 轴上方/下方
8. 应用：方案比较 → 联立找交点 → 分区间选择
```

### Day 5 综合练习（5 min）

```
1. 解不等式：−2(x − 1) ≥ 6，并在数轴上表示。
   → −2x+2 ≥ 6 → −2x ≥ 4 → x ≤ −2
   数轴：−2 处实心向左

2. 用图像法判断不等式 3x−6 < 0 的解集。
   → 画 y=3x−6，与 x 轴交于 (2,0)，下方对应 x<2

3. 联通套餐月租 15 元，通话 0.15 元/分。
   电信套餐月租 0 元，通话 0.35 元/分。
   一个月打多少分钟两套餐费用相同？
   → 15+0.15x = 0.35x → 15=0.2x → x=75 分钟
```
