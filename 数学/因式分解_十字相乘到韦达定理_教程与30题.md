## 知识串联

```
   十字相乘法                  韦达定理（Vieta）
   找 p,q 使              ↔     找 x₁,x₂ 使
   p+q = b                     x₁+x₂ = −b/a
   p×q = c                     x₁×x₂ =  c/a
       │                            │
       └──── 本质是同一种关系 ──────┘
                    │
                    ▼
       "因式分解 = 找根，找根 = 因式分解"

   双十字 = 十字在两个变量上的推广
```

## Part 1 · 十字相乘法（8 min·核心）

### 1.0 先让孩子看这个（1 分钟直观理解）

> **问题**：把 `x² + 7x + 10` 拆成两个括号的乘积 `(x + ？)(x + ？)`

思路就是找两个数，满足：

```
    和 = 7    ← 一次项的系数
    积 = 10   ← 常数项
```

让孩子自己试：哪两个数加起来 = 7，乘起来 = 10？

→ 2 和 5 ✓

所以：`x² + 7x + 10 = (x + 2)(x + 5)`

> 💡 **就这一件事**，剩下全是练习。告诉孩子：**"你只需要会找两个数"**。

### 1.1 本质

把 `x² + bx + c` 分解为 `(x + p)(x + q)`：

```
p + q = b       （和 = 一次项系数）
p × q = c       （积 = 常数项）
```

### 1.2 用 c 的符号快速判断 p, q 的符号（必教！）

**演示图**：

```
c > 0（积为正）              c < 0（积为负）
    p, q 同号                   p, q 异号
    ├─ b>0 → 都正              ├─ b>0 → 正的那个绝对值更大
    └─ b<0 → 都负              └─ b<0 → 负的那个绝对值更大
```

| 例 | 式子 | p, q 符号 | 结果 |
|---|------|------|------|
| c>0, b>0 | `x² + 7x + 10` | 都正 → 2, 5 | `(x+2)(x+5)` |
| c>0, b<0 | `x² − 5x + 6` | 都负 → −2, −3 | `(x−2)(x−3)` |
| c<0 | `x² − x − 12` | 一正一负 → −4, 3 | `(x−4)(x+3)` |

> 🎯 **教法**：让孩子先看 c 的符号，判断是同号还是异号，再凑 b。

### 1.3 首系数 ≠ 1：十字交叉演示图（本节重点）

把 `ax² + bx + c` 的首系数 a 和常数 c **都拆成两个数**，画一个叉：

```
           a₁           p          ← 拆 a 为 a₁×a₂
              \      /
               \    /
                \  /               ← 十字交叉相乘
                /  \
               /    \
              /      \
           a₂           q          ← 拆 c 为 p×q

     验证：a₁×q + a₂×p = b         ← 交叉乘积之和必须 = 中间项系数
     结果：(a₁x + p)(a₂x + q)      ← 横着读！
```

**例 4**：`3x² + 8x + 4`

```
拆 a=3 → 3, 1
拆 c=4 → 2, 2

      3x  ╲  ╱  2  ← 3x×2 = 6x
            ×
       x  ╱  ╲  2  ← x×2 = 2x
                      和 = 8x ✓

结果（横着读）：(3x + 2)(x + 2)

验证展开：
(3x+2)(x+2) = 3x² + 6x + 2x + 4 = 3x² + 8x + 4 ✓
```

**例 5**：`6x² − 7x − 3`

```
拆 a=6 → 2, 3
拆 c=−3 → −3, 1

      2x  ╲  ╱  1  ← 2x×1 = 2x
            ×
      3x  ╱  ╲ −3  ← 3x×(−3) = −9x
                       和 = −7x ✓

结果：(2x − 3)(3x + 1)     ← 横着读：2x→−3, 3x→1

验证展开：
(2x−3)(3x+1) = 6x² + 2x − 9x − 3 = 6x² − 7x − 3 ✓
```

> ⚠ **最容易犯的错**：竖着读！`2x → 1, 3x → −3` 写成 `(2x+1)(3x−3)` 是错的。
> 
> 记住：**交叉验证，横着读结果**。

### 🔍 检查理解

让孩子做这道题：`x² − 2x − 15`

```
问：c = −15 < 0，p 和 q 什么符号？（一正一负）
问：哪两个数乘起来 = −15，加起来 = −2？（−5 和 3）
答案：(x − 5)(x + 3)
```

## Part 2 · 双十字相乘法（6 min·跟着做一遍就会）

### 2.1 什么时候用

式子里有 **x 和 y 两个变量**，形如：

```
Ax² + Bxy + Cy² + Dx + Ey + F
```

### 2.2 演示全过程（带着孩子跟写）

**例题**：`x² + 3xy + 2y² + 4x + 5y + 3`

**第 1 步**：先不管 x 和 y 的一次项，只分解 `x² + 3xy + 2y²`：

```
      x  ╲  ╱  y   ← x×2y = 2xy
           ×
      x  ╱  ╲ 2y   ← x×y = xy
                      和 = 3xy ✓

→ (x + y)(x + 2y)
```

**第 2 步**：设 `(x + y + p)(x + 2y + q)`，展开后对比：

```
展开：(x+y+p)(x+2y+q) = x² + 3xy + 2y² 
                        + (p+q)x        ← 只看 x 的一次项
                        + (2p+q)y       ← 只看 y 的一次项
                        + pq            ← 常数

对比原式 x²+3xy+2y² + 4x + 5y + 3：

   p +  q = 4      ①  (x 系数)
  2p +  q = 5      ②  (y 系数)
   p × q = 3       ③  (常数)
```

**第 3 步**：解方程组

```
② − ①：p = 1
代入①：q = 3
验证③：1×3 = 3 ✓
```

**答案**：`(x + y + 1)(x + 2y + 3)`

> 🎯 **教法**：让孩子照抄这个过程做一遍题 16。双十字就是"十字 + 解个小方程组"，不神秘。

## Part 3 · 韦达定理 — 打通因式分解和方程（6 min）

### 3.1 韦达定理

对于方程 `ax² + bx + c = 0`（a ≠ 0），两根 x₁, x₂：

```
x₁ + x₂ = −b/a         ← 注意负号！
x₁ × x₂ =  c/a
```

### 3.2 和十字相乘的关系（一图看懂）

```
十字相乘（a=1 时）：          韦达定理（a=1 时）：
  找 p, q                      找 x₁, x₂
  p + q = b                    x₁ + x₂ = −b
  p × q = c                    x₁ × x₂ =  c

  关系：p = −x₁，q = −x₂

举同一个例子 x² − 5x + 6：
  十字相乘：(x−2)(x−3)    ← p=−2, q=−3
  韦达定理：x₁=2, x₂=3     ← x₁+x₂=5=−(−5), x₁x₂=6 ✓
```

> 🔑 **告诉孩子**："因式分解找的那两个数，就是方程两根的相反数。**因式分解 = 找根**，一回事情。"

### 3.3 三种用途（挑重点讲）

| # | 能做什么 | 例子 |
|---|------|------|
| ① | 已知一根，找另一根 | 2x²+kx+6=0, 一根=2 → 另一根=(6/2)/2=1.5 |
| ② | 不求解，求根的对称式 | 已知和与积 → 求 x₁²+x₂² |
| ③ | 已知两根，反写方程 | 根=3, −5 → x²+2x−15=0 |

### 🔍 检查理解

```
问：方程 x² − 8x + 15 = 0 的两根是多少？
答：找两个数，和 = 8，积 = 15 → 3 和 5

问：用韦达定理验算？
答：3+5=8=−(−8) ✓，3×5=15 ✓

问：因式分解是什么？
答：(x − 3)(x − 5)
```

## 孩子常见错误速查

| 错误表现 | 原因 | 怎么纠正 |
|------|------|------|
| 十字图画了但答案写反 | 竖着读而不是横着读 | 让孩子边写边说"横着读" |
| c<0 时符号搞反 | 没判断"异号"以及谁正谁负 | 先看 c 的符号，再看 b 的符号 |
| a≠1 时只拆 c 不拆 a | 忘了 a 也要拆 | 口诀："两头都拆，中间验证" |
| 双十字不敢下手 | 觉得看起来很难 | 说"就两步：十字 + 小方程" |
| 韦达符号写错 | 忘了根之和 = **−b/a** | 反复强调"有负号！" |
| 因式分解完没验算 | 跳步 | 规定：每写完一个答案立刻展开验一遍 |
