# 一元二次方程 · 由浅入深

> 八下 / 九上 | 浙教版 · 因式分解的直接应用场景

---

## 一、定义与标准形式

\[
\boxed{ax^2 + bx + c = 0 \quad (a \neq 0)}
\]

| 叫法 | 是什么 | 例：\(2x^2 - 3x + 1 = 0\) |
|------|--------|------|
| 二次项 | \(ax^2\)，系数 \(a\) | \(2x^2\)，\(a=2\) |
| 一次项 | \(bx\)，系数 \(b\) | \(-3x\)，\(b=-3\) |
| 常数项 | \(c\) | \(c=1\) |

> ⚠️ \(a \neq 0\)，否则退化为一元一次方程。\(b, c\) 可以为 0。

**三种退化形式（考试爱出）：**

| 类型 | 形式 | 解法 |
|------|------|------|
| \(b=0\) | \(ax^2 + c = 0\) | 直接开平方 |
| \(c=0\) | \(ax^2 + bx = 0\) | 提 \(x\) → 因式分解 |
| \(b=c=0\) | \(ax^2 = 0\) | \(x = 0\) |

---

## 二、解法一：直接开平方法 ⭐

> 适用条件：方程可化为 \(x^2 = k\) 或 \((x+m)^2 = k\)（无一次项）

\[
\boxed{x^2 = k \;\Longrightarrow\; x = \pm\sqrt{k} \quad (k \geq 0)}
\]

**例题：**

| 题 | 解 |
|------|------|
| \(x^2 = 9\) | \(x = \pm 3\) |
| \(x^2 = 7\) | \(x = \pm\sqrt{7}\)（留根号） |
| \(x^2 = -4\) | 无实数解（\(k<0\)） |
| \((x-2)^2 = 25\) | \(x-2 = \pm 5 \;\rightarrow\; x = 7 \text{ 或 } x = -3\) |
| \(2(x+1)^2 = 18\) | \((x+1)^2 = 9 \;\rightarrow\; x+1 = \pm 3 \;\rightarrow\; x = 2 \text{ 或 } x = -4\) |

---

## 三、解法二：因式分解法 ⭐⭐⭐

> 适用条件：方程左边能分解为两个一次因式的乘积，右边 = 0

\[
\boxed{(mx + n)(px + q) = 0 \;\Longrightarrow\; mx+n=0 \;\text{ 或 }\; px+q=0}
\]

> 🔥 你刚学的因式分解，最大用处就在这里！

### 1. 提公因式型（\(c=0\)）

\[
x^2 - 5x = 0 \;\rightarrow\; x(x-5) = 0 \;\rightarrow\; x = 0 \text{ 或 } x = 5
\]

### 2. 平方差型（\(b=0, c<0\)）

\[
x^2 - 16 = 0 \;\rightarrow\; (x+4)(x-4) = 0 \;\rightarrow\; x = \pm 4
\]

### 3. 十字相乘型

| 方程 | 因式分解 | 根 |
|------|---------|------|
| \(x^2 + 5x + 6 = 0\) | \((x+2)(x+3)=0\) | \(x=-2\) 或 \(x=-3\) |
| \(x^2 - x - 6 = 0\) | \((x+2)(x-3)=0\) | \(x=-2\) 或 \(x=3\) |
| \(2x^2 + 5x - 3 = 0\) | \((2x-1)(x+3)=0\) | \(x=\frac{1}{2}\) 或 \(x=-3\) |

### 🪄 符号速记

\[
x^2 + px + q = 0 \;\rightarrow\; (x+m)(x+n)=0
\]
其中 \(m+n = p,\; mn = q\)

## 四、解法三：配方法 ⭐⭐

> 把方程配成完全平方形式，是**公式法推导的基础**。

\[
\boxed{x^2 + px \;\longrightarrow\; x^2 + px + \left(\frac{p}{2}\right)^2 = \left(x + \frac{p}{2}\right)^2}
\]

**步骤：**

| 步 | 操作 | 例：\(x^2 + 6x - 7 = 0\) |
|:--:|------|------|
| 1 | 移常数项到右边 | \(x^2 + 6x = 7\) |
| 2 | 两边加 \(\left(\frac{b}{2}\right)^2\) | \(x^2 + 6x + 9 = 7 + 9\) |
| 3 | 左边写成完全平方 | \((x+3)^2 = 16\) |
| 4 | 开平方 | \(x+3 = \pm 4 \;\rightarrow\; x = 1 \text{ 或 } x = -7\) |

**首系数 ≠ 1 怎么办？**

\[
2x^2 + 8x - 10 = 0 \;\rightarrow\; x^2 + 4x - 5 = 0 \quad (\text{先两边同除以 }2)
\]

## 五、解法四：公式法 ⭐⭐⭐⭐⭐（万能法）

> 任何一元二次方程都能用，把 \(a, b, c\) 往里代就行。

\[
\boxed{x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}}
\]

**推导来源：** 对 \(ax^2+bx+c=0\) 配方得到的标准公式。

**例题：** \(2x^2 - 5x + 1 = 0\)

\[
a=2,\; b=-5,\; c=1
\]
\[
x = \frac{-(-5) \pm \sqrt{(-5)^2 - 4 \cdot 2 \cdot 1}}{2 \cdot 2}
= \frac{5 \pm \sqrt{25-8}}{4}
= \frac{5 \pm \sqrt{17}}{4}
\]

## 六、四种解法的选择策略 🎯

```
拿到方程→ 先看能不能直接开平方（无一次项）
         → 再看能不能因式分解（整数根首选）
         → 配方法（需要推导公式或题目指定）
         → 公式法（万能，根是无理数时必须用）
```

| 方程特征 | 首选方法 | 例子 |
|---------|---------|------|
| \(b=0\)，右边可开方 | 直接开平方 | \(x^2 = 25\) |
| 左边能一眼分解（整数根） | 因式分解 | \(x^2 + 5x + 6 = 0\) |
| 系数简单，根为有理数 | 配方或公式 | \(x^2 - 6x + 5 = 0\) |
| 系数复杂，根为无理数 | 公式法 | \(3x^2 - 2x - 7 = 0\) |

## 七、判别式 \(\Delta\) — 根的侦察兵

\[
\boxed{\Delta = b^2 - 4ac}
\]

| \(\Delta\) 的值 | 根的情况 | 图像（二次函数） |
|:---:|------|:---:|
| \(\Delta > 0\) | 两个**不等**实根 | 与 x 轴两个交点 |
| \(\Delta = 0\) | 两个**相等**实根（重根） | 与 x 轴一个切点 |
| \(\Delta < 0\) | 无实根（有共轭复根） | 与 x 轴无交点 |

**例题：** \(x^2 - 4x + 5 = 0\)

\[
\Delta = 16 - 20 = -4 < 0
\]
\(\Delta < 0\)，方程无实数解。

## 八、🟡 韦达定理（根与系数关系）

\[
\boxed{x_1 + x_2 = -\frac{b}{a}} \qquad
\boxed{x_1 x_2 = \frac{c}{a}}
\]

> 对 \(ax^2 + bx + c = 0\)，当 \(\Delta \geq 0\) 时成立。

### 不用解方程，直接求对称式

| 要求的量 | 用 \(x_1+x_2\) 和 \(x_1x_2\) 表达 |
|---------|------|
| \(x_1^2 + x_2^2\) | \((x_1+x_2)^2 - 2x_1x_2\) |
| \(\frac{1}{x_1} + \frac{1}{x_2}\) | \(\frac{x_1+x_2}{x_1x_2}\) |
| \((x_1 - x_2)^2\) | \((x_1+x_2)^2 - 4x_1x_2\) |
| \(\lVert x_1 - x_2\rVert\) | \(\frac{\sqrt{\Delta}}{\lVert a\rVert}\) |

### 构造方程

> 以 \(p, q\) 为根的一元二次方程：\(x^2 - (p+q)x + pq = 0\)

## 九、🟡 常见应用题模型

### 模型一：增长率问题

> 基数为 \(a\)，每次增长率为 \(x\)，两次后为 \(b\)
> \[
> a(1+x)^2 = b
> \]

例：某商品原价 100 元，两次提价后 121 元，设每次提价 \(x\%\)：
\[
100(1+x)^2 = 121 \;\rightarrow\; (1+x)^2 = 1.21 \;\rightarrow\; 1+x = 1.1 \;\rightarrow\; x = 10\%
\]

### 模型二：矩形面积问题

> 围栏长 \(L\)，围成长方形，设宽 \(=x\)，则长 \(= \frac{L}{2} - x\)，面积记为 \(S\)
> \[
> x\left(\frac{L}{2} - x\right) = S \;\Rightarrow\; x^2 - \frac{L}{2}x + S = 0
> \]

### 模型三：数字与平方问题

> "两个连续奇数的积是 143，求这两个数"
> \[
> x(x+2) = 143 \;\rightarrow\; x^2+2x-143 = 0 \;\rightarrow\; (x+13)(x-11) = 0
> \]
> 正数解：11 和 13。

### 模型四：利润最大化 🔴

> 进价 \(c\)，售价 \(p\)，销量 \(n\) 与售价相关
> \[
> L = (p - c) \cdot n
> \]
> \(L\) 是 \(p\) 的二次函数 → 配方或公式求最值
