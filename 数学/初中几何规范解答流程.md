# 初中几何 — 规范解答流程与示例

---

## 一、几何题通用解答框架

### 1.1 标准书写结构

| 环节 | 说明 | 示例开头 |
|------|------|----------|
| **已知** | 从题干提取所有已知条件，可用符号简化 | ∵ AB = CD，∠A = ∠D |
| **求证/求解** | 明确目标 | 求证：△ABC ≅ △DCB |
| **证明/解** | 逐步推理，每一步附依据 | ∵ AB = CD（已知），… |
| **结论** | 呼应问题 | ∴ △ABC ≅ △DCB |

### 1.2 推理链格式

```
∵ 条件1, 条件2（理由）
∴ 结论1（理由）

∵ 结论1, 条件3（理由）
∴ 结论2（理由）

…逐层推进…

∴ 最终结论
```

> 核心原则：**每一步都要有"因为"和"所以"，每一步都要注明理由。**

## 二、证明类题型示例

### 例 1：全等三角形证明（基础）

> 如图，AB = AC，D 是 BC 中点。
> 求证：AD ⊥ BC。

<div align="center">

<svg width="260" height="280" viewBox="0 0 260 280">
  <!-- 三角形 ABC -->
  <polygon points="130,20 20,240 240,240" fill="none" stroke="#333" stroke-width="2"/>
  <!-- 中线 AD -->
  <line x1="130" y1="20" x2="130" y2="240" stroke="#333" stroke-width="2" stroke-dasharray="6,3"/>
  <!-- 直角标记 -->
  <rect x="120" y="230" width="10" height="10" fill="none" stroke="#333" stroke-width="1.5"/>
  <!-- 等边标记 AB=AC -->
  <line x1="75" y1="130" x2="95" y2="120" stroke="#e44" stroke-width="2"/>
  <line x1="165" y1="120" x2="185" y2="130" stroke="#e44" stroke-width="2"/>
  <!-- 等边标记 BD=DC -->
  <line x1="100" y1="248" x2="110" y2="238" stroke="#44e" stroke-width="2"/>
  <line x1="150" y1="238" x2="160" y2="248" stroke="#44e" stroke-width="2"/>
  <!-- 标注 -->
  <text x="135" y="12" fill="#333" font-size="16" text-anchor="middle">A</text>
  <text x="2" y="248" fill="#333" font-size="16">B</text>
  <text x="252" y="248" fill="#333" font-size="16">C</text>
  <text x="140" y="135" fill="#333" font-size="16">D</text>
</svg>

</div>

```
已知：AB = AC，D 为 BC 中点，即 BD = CD
求证：AD ⊥ BC

证明：

在 △ABD 和 △ACD 中：
  ∵ AB = AC        （已知）
     BD = CD        （已知，D 为 BC 中点）
     AD = AD        （公共边）
  ∴ △ABD ≅ △ACD   （SSS）

  ∴ ∠ADB = ∠ADC   （全等三角形对应角相等）

  又 ∵ ∠ADB + ∠ADC = 180°  （平角定义）
  ∴ 2∠ADB = 180°
  ∴ ∠ADB = 90°
  ∴ AD ⊥ BC        （垂直定义）
```

```

求证：EF ∥ GH

证明：

∴ ∠1 = ∠3 = 60°    （两直线平行，同位角相等）

∵ ∠2 = 120°（已知）
∴ ∠2 + ∠3 = 120° + 60° = 180°

又 ∵ ∠2 与 ∠3 是同旁内角
∴ EF ∥ GH          （同旁内角互补，两直线平行）
```

## 三、计算类题型示例

### 例 3：勾股定理应用

> 如图，在 Rt△ABC 中，∠C = 90°，AC = 6，BC = 8。
> 求 AB 的长。

<div align="center">

<svg width="280" height="240" viewBox="0 0 280 240">
  <!-- 直角三角形 -->
  <polygon points="40,200 40,40 240,200" fill="#f0f4ff" stroke="#333" stroke-width="2"/>
  <!-- 直角标记 -->
  <rect x="40" y="180" width="20" height="20" fill="none" stroke="#333" stroke-width="1.5"/>
  <!-- 标注 -->
  <text x="28" y="210" fill="#333" font-size="16" text-anchor="end">A</text>
  <text x="30" y="32" fill="#333" font-size="16" text-anchor="end">B</text>
  <text x="250" y="210" fill="#333" font-size="16" text-anchor="start">C</text>
  <!-- 边长标注 -->
  <text x="10" y="120" fill="#e44" font-size="14">6</text>
  <text x="130" y="220" fill="#e44" font-size="14">8</text>
  <text x="150" y="110" fill="#44e" font-size="15" font-weight="bold">?</text>
</svg>

</div>

```
已知：在 Rt△ABC 中，∠C = 90°，AC = 6，BC = 8
求解：AB

解：

在 Rt△ABC 中，由勾股定理得：
  AB² = AC² + BC²
  AB² = 6² + 8²
  AB² = 36 + 64 = 100

  ∴ AB = √100 = 10      （负值舍去）

答：AB 的长为 10。
```

### 例 4：圆的计算

> 如图，⊙O 中，弦 AB 所对圆心角 ∠AOB = 120°，半径 r = 6。
> 求弦 AB 的长。

<div align="center">

<svg width="260" height="260" viewBox="0 0 260 260">
  <!-- 圆 -->
  <circle cx="130" cy="130" r="100" fill="none" stroke="#333" stroke-width="2"/>
  <text x="130" y="126" fill="#333" font-size="16" text-anchor="middle">O</text>
  <!-- 半径 OA -->
  <line x1="130" y1="130" x2="225" y2="62" stroke="#333" stroke-width="1.5"/>
  <text x="232" y="56" fill="#333" font-size="14">A</text>
  <!-- 半径 OB -->
  <line x1="130" y1="130" x2="35" y2="62" stroke="#333" stroke-width="1.5"/>
  <text x="18" y="56" fill="#333" font-size="14">B</text>
  <!-- 弦 AB -->
  <line x1="225" y1="62" x2="35" y2="62" stroke="#e44" stroke-width="2"/>
  <!-- 圆心角标记 -->
  <path d="M 213,80 A 100,100 0 0,0 47,80" fill="none" stroke="#44e" stroke-width="1.5"/>
  <text x="130" y="30" fill="#44e" font-size="14" text-anchor="middle">120°</text>
  <!-- 半径标注 -->
  <text x="180" y="100" fill="#888" font-size="12">r=6</text>
</svg>

</div>

```
已知：⊙O 半径 r = 6，圆心角 ∠AOB = 120°
求解：弦 AB 的长

解：

法一（垂径定理）：

过 O 作 OC ⊥ AB 于 C，连接 OA
  ∵ OA = OB = 6
  ∴ OC 平分 ∠AOB        （等腰三角形三线合一）
  ∴ ∠AOC = 60°

在 Rt△AOC 中：
  ∵ ∠AOC = 60°, OA = 6
  ∴ AC = OA × sin60° = 6 × √3/2 = 3√3

  ∵ OC ⊥ AB
  ∴ AB = 2 × AC = 6√3

答：弦 AB 的长为 6√3。
```

## 四、规范解答评分要点

### 4.1 证明题评分标准

| 得分点 | 说明 |
|--------|------|
| 条件转化 | 正确标注和转译已知条件 |
| 推理链完整 | 每一步都有因果，不跳步 |
| 依据充分 | 每步注明定理/公理/定义 |
| 结论明确 | 与"求证"完全呼应 |

### 4.2 计算题评分标准

| 得分点 | 说明 |
|--------|------|
| 公式正确 | 选用恰当的定理/公式 |
| 代入无误 | 数值代入准确，单位正确 |
| 计算过程 | 关键中间步骤保留 |
| 答案规范 | 有"答"，结果化简到最简 |

### 4.3 常见扣分项

| 扣分项 | 说明 |
|--------|------|
| 跳步 | 缺少关键中间推理 |
| 缺依据 | 结论后面没写理由（SSS/SAS/AAS 等） |
| 格式混乱 | "已知""求证"不明确区分 |
| 漏答 | 计算题没有最后的"答：" |
| 符号错误 | ∵ ∴ 用反、角的写法不规范 |
| 单位遗漏 | 长度、角度、面积无单位 |

## 五、常用定理速查

### 5.1 平行线

| 判定 | 性质 |
|------|------|
| 同位角相等 → 两直线平行 | 两直线平行 → 同位角相等 |
| 内错角相等 → 两直线平行 | 两直线平行 → 内错角相等 |
| 同旁内角互补 → 两直线平行 | 两直线平行 → 同旁内角互补 |

### 5.2 全等三角形

| 判定公理 | 含义 |
|----------|------|
| SSS | 三边对应相等 |
| SAS | 两边及其夹角对应相等 |
| ASA | 两角及其夹边对应相等 |
| AAS | 两角及其中一角的对边对应相等 |
| HL | 斜边和一条直角边对应相等（仅 Rt△） |

### 5.3 特殊三角形

| 类型 | 核心性质 |
|------|----------|
| 等腰三角形 | 等边对等角；三线合一（顶角平分线 = 底边中线 = 底边高） |
| 等边三角形 | 三角均为 60°；四心合一 |
| 直角三角形 | 勾股定理；斜边中线 = 斜边一半；30° 对边 = 斜边一半 |

### 5.4 圆

| 定理 | 内容 |
|------|------|
| 垂径定理 | 垂直于弦的直径平分这条弦及所对的两条弧 |
| 圆周角定理 | 同弧所对圆周角 = 圆心角的一半 |
| 切线性质 | 切线垂直于过切点的半径 |
| 弦切角定理 | 弦切角 = 所夹弧对的圆周角 |

## 附录：几何书写示范口诀

> 已知条件先列清，求证目标写分明；  
> 推理步步有依据，全等相似标注清；  
> ∵ ∴ 符号不乱用，对应字母要对齐；  
> 最后结论要呼应，不漏不跳才得分。
