# 分数约分技巧

---

## 一、核心原理

**约分 = 分子分母同时除以最大公约数 (GCD)。** 求 GCD 三条路：

| 方法 | 何时用 | 口诀 |
|------|--------|------|
| **差值法** | 两数接近（差 < 50） | 差小试因，从大到小 |
| **辗转相除** | 差距大、不好判断 | 反复取余，余 0 则停 |
| **质因数分解** | 数字小、因子明显 | 各拆质因数，约公共部分 |

---

## 二、差值法（最快）

**核心定理：若 d 同时整除 a 和 b，则 d 也整除 (a−b)。**

拿到差值 D 后，从大到小试 D 的因数，第一个同时整除分子分母的就是 GCD。

```
391/425：

D = 425−391 = 34
34 因数：34, 17, 2, 1
34 不整除 391 ✗
17 整除 391 且整除 425 ✓  →  GCD = 17

391÷17=23，425÷17=25  →  23/25
```

```
133/152：

D = 152−133 = 19  （19 是质数）
19 整除 133=7×19，整除 152=8×19 ✓  →  GCD = 19

133÷19=7，152÷19=8  →  7/8
```

```
221/247：

D = 247−221 = 26
26 因数：26, 13, 2, 1
13 整除 221 ✓  →  GCD = 13  →  17/19
```

---

## 三、辗转相除法（最稳）

反复：大 ÷ 小 → 余数 r，然后小 ÷ r → 新余数，直到余 0。

```
437/551：

551 ÷ 437 = 1 余 114
437 ÷ 114 = 3 余 95
114 ÷ 95  = 1 余 19
95  ÷ 19  = 5 余 0   ← 停止，GCD = 19

437÷19=23，551÷19=29  →  23/29
```

```
667/713：

713 ÷ 667 = 1 余 46
667 ÷ 46  = 14 余 23
46  ÷ 23  = 2 余 0   ← 停止，GCD = 23

667÷23=29，713÷23=31  →  29/31
```

## 四、质因数分解法（数字小时好用）

```
84/196：

84  = 2² × 3 × 7
196 = 2² × 7²
公共 = 2² × 7 = 28  →  3/7
```

```
231/385：

231：2+3+1=6 → 有因子 3  →  231 = 3×7×11
385：末位 5  →  有因子 5  →  385 = 5×7×11
公共 = 7×11 = 77  →  3/5
```

## 五、短除法（质因数分解的快捷写法）

同时用公共质因数反复约分子分母：

```
      2 │ 84  196         12 │ 144  360
      2 │ 42  98           6 │ 12   30
      7 │ 21  49             │ 2    5
        │ 3   7
                            GCD=12×6=72
  GCD=2×2×7=28 → 3/7       → 2/5
```

> 不必非从小质数开始 — 一眼看出公因数就一大步跨过去（如右边直接用 12）。

## 六、1001 法：秒杀含 7/11/13 因子的分数

利用 **1001 = 7×11×13**。三位分段，奇段和 − 偶段和，差能被 7/11/13 整除则原数也能。

```
1001/1716：

分子 1001 = 7×11×13
分母 1716：001|716 → 716−1=715=5×11×13  →  含 11×13
公共 = 11×13 = 143  →  7/12
```

```
143/286：

143 = 11×13
286：286−0=286 → 286=2×11×13  →  含 11×13
公共 = 11×13 = 143  →  1/2
```

此法适合分子或分母含 1001、715、286 这类"一眼像 7×11×13 倍数"的数。

## 七、常用因子速判表

| 除数 | 判定 | 除数为 | 判定 |
|------|------|--------|------|
| 2 | 末位偶数 | 7 | 截尾−2×末位，或三位分段 |
| 3 | 数字和 ÷3 | 8 | 末三位 ÷8 |
| 4 | 末两位 ÷4 | 9 | 数字和 ÷9 |
| 5 | 末位 0/5 | 11 | 奇偶位差 ÷11 |
| 6 | 同时被 2 和 3 整除 | 13 | 截尾+4×末位，或三位分段 |

### 7 的截尾法速判

```
371 → 37 − 1×2 = 35 ✓
2037 → 203 − 7×2 = 189 → 18 − 9×2 = 0 ✓
```

### 11 的奇偶位差法

```
2728 → (8+7)−(2+2)=11 ✓
```

### 13 的截尾加 4 倍法

```
351 → 35 + 1×4 = 39 = 3×13 ✓
```

## 八、约分实战流程

```
拿到分数 → ① 差值 < 50？→ 差值法秒杀
          ② 分子或分母像 7/11/13 倍数？→ 1001 三位分段法
          ③ 末位有 0/5？数字和 ÷3？→ 2/3/5 快筛
          ④ 都不行 → 辗转相除法兜底
```

## 九、精练习题

### 1. 323/391

```
差值法：D = 391−323 = 68 = 2²×17
因数从大到小：68, 34, 17 → 17 命中
323÷17=19, 391÷17=23  →  19/23

辗转法验证：
391÷323=1 余 68 → 323÷68=4 余 51 → 68÷51=1 余 17 → 51÷17=3 余 0
GCD=17
```

### 2. 299/529

```
差值法：D = 529−299 = 230 = 2×5×23
因数：230, 115, 46, 23... → 23 命中
299=13×23, 529=23²  →  13/23

想快一点：299 末两位不是 23 的倍数所以 46 不整除；230 太大；试 23 立刻对。
```

### 3. 851/943

```
辗转法：
943÷851 = 1 余 92
851÷92  = 9 余 23
92÷23   = 4 余 0  →  GCD = 23

851÷23=37, 943÷23=41  →  37/41
```
