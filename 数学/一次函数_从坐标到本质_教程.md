## 教学指南（给家长/老师）

```
教这个的顺序：
```

## 一、坐标系 — 把平面变成"地图"

### 1.1 直观理解

> 告诉孩子：**坐标系就是把平面变成一张地图。每个点都有一个"地址"(x, y)，就像每家有门牌号。**

```
              y 轴 (纵轴)
                ↑
                |
            Q2  |  Q1       ← 第一象限
        (−,+)  |  (+,+)
                |
    —————————————+————————————→  x 轴 (横轴)
                | 原点 O(0,0)
            Q3  |  Q4
        (−,−)  |  (+,−)
                |
```

| 象限 | x 符号 | y 符号 | 例如 |
|:--:|:--:|:--:|------|
| 第一象限 Q1 | + | + | (3, 5) |
| 第二象限 Q2 | − | + | (−4, 2) |
| 第三象限 Q3 | − | − | (−1, −6) |
| 第四象限 Q4 | + | − | (5, −3) |
| x 轴上 | 任意 | 0 | (7, 0) |
| y 轴上 | 0 | 任意 | (0, −2) |

**核心规则**：
- `(x, y)` — **先横后纵**，横坐标在前、纵坐标在后
- 原点 = `(0, 0)` — 一切坐标的起点

### 1.2 点的移动和对称

| 操作 | 规则 | 例：(2, 3) → ? |
|------|------|------|
| 向右平移 a | x + a, y 不变 | (2,3) 右移 3 → (5,3) |
| 向左平移 a | x − a, y 不变 | (2,3) 左移 2 → (0,3) |
| 向上平移 a | x 不变, y + a | (2,3) 上移 4 → (2,7) |
| 向下平移 a | x 不变, y − a | (2,3) 下移 1 → (2,2) |
| 关于 x 轴对称 | y 变号 | (2,3) → (2,−3) |
| 关于 y 轴对称 | x 变号 | (2,3) → (−2,3) |
| 关于原点对称 | x, y 都变号 | (2,3) → (−2,−3) |

### 🔍 小练习

```
1. 点 A(3, −4) 在第几象限？（第四象限）
2. A(3,−4) 关于 x 轴对称的点是？（3, 4）
3. A(3,−4) 向上平移 5 个单位？（3, 1）
```

## 二、y = kx + b — 一次函数的本质

### 2.1 先看一个实际例子，再抽象

> 出租车：起步价 **8 元**，每公里 **2 元**。
>
> 坐了 x 公里，总价 y = **2x + 8**

```
x = 0  →  y = 8     ← 还没出发就要 8 元（起步价）
x = 1  →  y = 10    ← 多 2 元
x = 2  →  y = 12    ← 又多 2 元
x = 3  →  y = 14
...
```

**规律**：x 每增加 1，y 就增加 2。这就是 `k = 2` 的含义。

### 2.2 本质定义

> 一次函数 `y = kx + b`（k ≠ 0）：
> - **k** = **变化率**（斜率）：x 每增加 1，y 就改变 k
> - **b** = **初始值**（截距）：x = 0 时的 y 值，也就是"起步位置"

```
y = kx + b
     ↑    ↑
   "步长"  "起点"

用生活的话说：
  k = 每走一步变化多少
  b = 从哪开始
```

### 2.3 给孩子建立直觉

| k 的值 | 含义 | 图像感觉 |
|:--:|------|------|
| k > 0 | x 越大 y 越大 | 上坡路 ↗ |
| k < 0 | x 越大 y 越小 | 下坡路 ↘ |
| k = 0 | y 固定不变 | 平路 →（y = b，常数函数） |
| \|k\| 越大 | 变得越快 | 越陡 |
| \|k\| 越小 | 变得越慢 | 越平缓 |

```
 k > 0:          k < 0:          k = 0:
   ↗              ↘               →
 上坡路          下坡路          平路
 (递增)          (递减)          (不变)
```

### 2.4 演示 k 和 b 分别控制什么

```
y = 2x + 0      y = 2x + 3      y = 2x − 3
    │               │               │
    └── k=2 一样陡，b 不同，三条平行线上下平移

          y = 2x    y = x/2    y = −x
            │          │         │
           陡         缓       下降
```

> 🎯 **核心结论**：
> - **k 决定方向 + 坡度**（k 相同 → 平行）
> - **b 决定高低**（b 是直线与 y 轴的交点）

## 三、画图 — 两点定一直线

### 3.1 基本方法

一次函数的图像是一条**直线**，画直线只需要**两个点**：

```
方法 1：截距法
  第 1 点：x=0  →  y=b        ← (0, b) 就是与 y 轴的交点
  第 2 点：y=0  →  x=−b/k    ← (−b/k, 0) 就是与 x 轴的交点

方法 2：任意两点（更常用）
  随便取两个 x 值，算对应的 y，连线
```

**例**：画 `y = 2x − 4`

```
取 x = 0：y = −4  →  点 (0, −4)
取 x = 3：y = 2   →  点 (3, 2)

在坐标系中描出两点，用直尺连成直线。
```

```
                ↑ y
                |
                |        ● (3, 2)
                |       /
                |      /
                |     /
                |    /
  —————————————+——/——————→ x
                | /
                |/
                ● (0, −4)
                |
```

### 3.2 从图像读 k 和 b

反过来，看到一张图，怎么读取 k 和 b？

1. **先读 b**：看直线与 y 轴交点的纵坐标 → 就是 b
2. **再读 k**：沿直线从左往右，"前进 1 格，上升/下降几格" → 就是 k

```
演示（跟孩子一起操作）：

  b = 直线交 y 轴的高度（一眼就能看出来）
  k = 选直线上两个好读的点（格子交叉处），
      用 (y₂−y₁)/(x₂−x₁) 算出来
```

**例**：直线上有两点 (1, 3) 和 (4, 9)

```
k = (9 − 3) / (4 − 1) = 6 / 3 = 2
```

> 每往右走 1 格 → 往上走 2 格，所以 k = 2。

### 🔍 检查理解

```
1. y = −3x + 5 的 k 和 b 各是多少？图像从左往右是上升还是下降？
   （k=−3, b=5，下降——因为 k<0）

2. 一条直线经过 (0, 2) 和 (3, 8)，求 k 和 b？
   （b=2, k=(8−2)/(3−0)=2, 所以 y=2x+2）
```

## 四、一次函数的平移

> 只改 b，直线**上下平移**（k 不变 → 方向不变）

| 操作 | 效果 |
|------|------|
| b 增大 | 整条线**向上**平移 |
| b 减小 | 整条线**向下**平移 |

```
y = 2x       → 过原点，b=0
y = 2x + 3   → 整条线往上移 3 格
y = 2x − 1   → 整条线往下移 1 格

（三条线完全平行，只是高度不同）
```

## 五、两条直线的位置关系

| 关系 | 判定 | 图示 |
|------|------|:--:|
| **平行** | `k₁ = k₂` 且 `b₁ ≠ b₂` | ∥ 方向相同，高度不同 |
| **重合** | `k₁ = k₂` 且 `b₁ = b₂` | 同一条线 |
| **相交** | `k₁ ≠ k₂` | × 在某一点交叉 |
| **垂直**（拓展） | `k₁ × k₂ = −1` | ⟂ 如 k=2 和 k=−1/2 |

**两直线交点**：联立两个方程，解方程组。交点的坐标 = 方程组的解。

**例**：y = 2x + 1 和 y = −x + 7

```
2x + 1 = −x + 7
3x = 6
x = 2,  y = 2×2+1 = 5
交点：(2, 5)
```

画图验证：一条 ↗ 一条 ↘，在 (2,5) 交叉。

## 六、一次函数与方程/不等式（一图三用）

一张图，三个问题，一个答案：

```
图中画 y = 2x − 4：

        y = 2x−4
            ↑
            |     /
            |    /
            |   /
  ─────────+──/───→  y = 0（x 轴）
            | /
            |/
            ● (2, 0)
            |
            |  直线在 x 轴上方 → y > 0
            |  直线在 x 轴下方 → y < 0

1. 方程 2x−4=0 的解？  →  x=2（直线与 x 轴交点）
2. 不等式 2x−4>0 的解？ → x>2（直线在 x 轴上方部分）
3. 不等式 2x−4<0 的解？ → x<2（直线在 x 轴下方部分）
```

> 🎯 告诉孩子：**不等式不用背方向，看图就行！**

## 常见错误速查

| 错误 | 原因 | 纠正方法 |
|------|------|------|
| (x, y) 写反 | 不记"先横后纵" | 口诀："横在前纵在后，就像先说楼号再说房间号" |
| k 公式分子分母反 | 不理解为"Δy/Δx" | 带孩子从图上数格子：横着走几格，竖着变几格 |
| 写完表达式不验算 | 跳步 | 拿已知点代回去检验，成为习惯 |
| 分段函数忘写范围 | 不懂"条件变了公式也变" | 先说"当 x>某值时"，再写表达式 |
| 求交点只写 x 不写 y | 以为交点是数字不是坐标 | 强调"交点是一个点，必须(x, y)" |
| 不等号方向推理混乱 | 死背规则不看图 | 画出直线，看 x 轴上方/下方直接判断 |
