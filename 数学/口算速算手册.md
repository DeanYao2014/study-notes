### 7 / 11 / 13（重点）

此三者统一定理：**三位分段奇偶差法**

> 从右往左每三位一组，(奇数段之和) − (偶数段之和)  
> 若差能被 7 / 11 / 13 整除，则原数也能。

```
判断 11683：
  分段：011 | 683  →  奇段 683，偶段 11
  差：683 − 11 = 672
  672 ÷ 7 = 96 ✓  →  11683 能被 7 整除
  672 ÷ 13 ≈ 51.7 ✗  →  不能
```

**原理：1001 = 7 × 11 × 13**，三位一组本质是模 1001 运算。

## 三、余数特性与同余问题

### 3.1 基础概念

```
N = d × q + r     0 ≤ r < d

例：37 ÷ 5 = 7 余 2  →  37 = 5×7 + 2
```

**余数运算律：**

- **(a+b) mod m = (a mod m + b mod m) mod m**
- **(a×b) mod m = (a mod m × b mod m) mod m**
- 若 a ≡ b (mod m)，则 a±c ≡ b±c，a×c ≡ b×c

**周期本质：** 余数相同 = 在同一"余数类"中。钟表（mod 12）、星期（mod 7）、生肖（mod 12）都是此理。

---

### 3.2 同余三类型

#### 类型一：余同（最直观）

> 某数被多个除数除，**余数相同**。  
> → 该数减余数 = 所有除数的公倍数。

```
【例】某数除以3余2，除以5余2，除以7余2，求最小正整数。

解：N − 2 同时是 3、5、7 的倍数
    N − 2 = LCM(3,5,7) × k = 105k
    N_min = 105×0 + 2 = 2（或取 107 作为非零解）

公式：N = LCM × k + r
```

#### 类型二：和同

> 被多个除数除，**除数 + 余数 = 定值 S**。  
> → N − S = 所有除数的公倍数。

```
【例】某数除以4余3，除以5余2，除以6余1。

观察：4+3=7，5+2=7，6+1=7  ← 和同为 7

解：N − 7 = 4(q₁−1) = 5(q₂−1) = 6(q₃−1)
    即 N − 7 同时是 4、5、6 的公倍数
    N − 7 = LCM(4,5,6) × k = 60k
    N = 60k + 7
    N_min = 7（k=0），下一解 67

验证：7÷4=1 余 3 ✓，7÷5=1 余 2 ✓，7÷6=1 余 1 ✓
      67÷4=16 余 3 ✓，67÷5=13 余 2 ✓，67÷6=11 余 1 ✓

公式：N = LCM × k + S   （S = 除数+余数 的共同值）
```

#### 类型三：差同

> 被多个除数除，**除数 − 余数 = 定值 D**。  
> → N + D = 所有除数的公倍数。

```
【例】某数除以3余1，除以5余3，除以7余5。

观察：3−1=2，5−3=2，7−5=2  ← 差同为 2

解：N + 2 = 3(q₁+1) = 5(q₂+1) = 7(q₃+1)
    即 N + 2 同时是 3、5、7 的公倍数
    N + 2 = LCM(3,5,7) × k = 105k
    N = 105k − 2
    N_min = 103（首正解）

验证：103÷3=34 余 1 ✓，103÷5=20 余 3 ✓，103÷7=14 余 5 ✓

公式：N = LCM × k − D   （D = 除数−余数 的共同值）
```

#### 三类型速判口诀

```
一看余数是否同 → 余同，减余即公倍
二看除加余是否同 → 和同，减和即公倍  
三看除减余是否同 → 差同，加差即公倍
三步都不中 → 逐步满足法
```

---

### 3.3 混合型：逐步满足法

```
【例】某数除以3余2，除以5余3，除以7余2。求最小解。

Step 1 — 合并同类：
  除以3余2、除以7余2  →  余同！N = 21k + 2

Step 2 — 代入剩余条件：
  N = 21k + 2，还要除以5余3
  N mod 5 = (21k+2) mod 5 = (k+2) mod 5 = 3
  → k mod 5 = 1  →  k = 5m+1

Step 3 — 回代：
  N = 21(5m+1) + 2 = 105m + 23
  N_min = 23

验证：23÷3=7余2 ✓，23÷5=4余3 ✓，23÷7=3余2 ✓
```

---

### 3.4 应用题秒杀

**周期问题 — 都用模运算：**

```
【星期】2026年5月9日是周六，100天后星期几？

  100 mod 7 = 2（因为 98 是 14×7）
  周六 + 2天 = 周一

直接答案：星期一。无需逐月数。
```

```
【韩信点兵】一队士兵，3人一排剩2人，5人一排剩3人，7人一排剩2人。

  识别：除以3余2、除以5余3、除以7余2
  → 3和7余同！合并：N=21k+2
  → 代入除以5余3：(21k+2)mod5=(k+2)mod5=3 → k=5m+1
  → N=105m+23，最小 23 人
```

```
【余数定位】一本书页码，被3除余1，被5除余4，被7除余3。最少几页？

  3-1=2, 5-4=1, 7-3=4  → 都不相同，差也不同，和也不同
  → 逐步满足法

  N=3a+1 → 即 N=1,4,7,10,13,16,19,22,25,28,31,34,37,40...
  筛除以5余4：N=4,19,34 → 通式 N=15k+4
  代入除以7余3：(15k+4)mod7=(k+4)mod7=3 → kmod7=6 → k=7m+6
  N=15(7m+6)+4=105m+94 → N_min=94

  验证：94÷3=31余1 ✓，94÷5=18余4 ✓，94÷7=13余3 ✓
```

## 四、速算技巧（15 招）

### 加减

**1. 补数凑整** — 接近整十整百的数，先取整再调整。

```
997+456 = 1000+456−3 = 1453
527−298 = 527−300+2 = 229
```

**2. 高位分段** — 从左往右分段算，避免进位记忆。

```
348+275：300+200=500, 40+70=110→610, 8+5=13→623
```

### 乘法

**3. ×5 / ×25 / ×125** — 化乘为除。

```
×5 = ×10÷2    68×5 = 680÷2 = 340
×25 = ×100÷4   36×25 = 3600÷4 = 900
×125 = ×1000÷8  88×125 = 88000÷8 = 11000
```

**4. ×9 / ×99** — 化乘为减。

```
57×9 = 570−57 = 513
23×99 = 2300−23 = 2277
```

**5. ×11** — 两头一拉，中间相加（注意进位）。

```
23×11 → 2 (2+3) 3 = 253
67×11 → 6 (6+7) 7 = 6 13 7 → 进位 737
234×11 → 2 (2+3) (3+4) 4 = 2574
```

**6. 末位 5 平方** — 头×头加一，尾写 25。

```
35² → 3×4|25 = 1225
85² → 8×9|25 = 7225
125² → 12×13|25 = 15625
```

**7. 近 100 相乘** — 补数交叉。

```
98×97（98 缺 2，97 缺 3）
→ 前两位：100−2−3=95  |  后两位：2×3=06  → 9506

102×103（多 2，多 3）
→ 前两位：100+2+3=105  |  后两位：2×3=06  → 10506
```

**8. 首同尾合十** — 十位相同，个位和=10。

```
34×36 → 3×4|4×6 = 12|24 = 1224
72×78 → 7×8|2×8 = 56|16 = 5616
```

**9. 平方差乘** — (a+b)(a−b) = a²−b²。

```
29×31 = 30²−1² = 900−1 = 899
48×52 = 50²−2² = 2500−4 = 2496
```

### 除法

**10. ÷5 / ÷25 / ÷125** — 化除为乘。

```
÷5 = ×2÷10     340÷5 = 680÷10 = 68
÷25 = ×4÷100    175÷25 = 700÷100 = 7
÷125 = ×8÷1000  750÷125 = 6000÷1000 = 6
```

**11. ÷0.5 / ÷0.25** — 直接翻倍。

```
÷0.5 = ×2    ÷0.25 = ×4    ÷0.2 = ×5    ÷0.125 = ×8
```

**12. 特殊除数百分数法** — 用表2的对应乘数反推。

```
300÷7 ≈ 300×0.143 = 42.9  （精确 42.857）
100÷12 = 100×0.0833 = 8.33
```

### 平方/开方

**13. 末位 1/9 平方** — 利用 (a±1)²。

```
31² = 30²+2×30+1 = 900+60+1 = 961
29² = 30²−2×30+1 = 900−60+1 = 841
```

**14. 通用两位数平方** — (a+b)² = a²+2ab+b²。

```
37² = 30²+2×30×7+7² = 900+420+49 = 1369
86² = 80²+2×80×6+6² = 6400+960+36 = 7396
```

**15. 平方根夹逼** — √N ≈ a + (N−a²)/(2a)，a² 是最近整平方。

```
√50 ≈ 7 + (50−49)/(2×7) = 7 + 1/14 ≈ 7.071  （精确 7.0711）
√200 ≈ 14 + (200−196)/(2×14) = 14 + 4/28 ≈ 14.143  （精确 14.1421）
```

### 验算双保险

**弃九法：** A×B=C → (A 的各位和 mod 9) × (B 的各位和 mod 9) ≡ (C 的各位和 mod 9)

```
37×53=1961?
  37→10→1, 53→8→8, 1×8=8
  1961→17→8 ✓ （极大概率正确）
```

**末位法：** 结果的末位 = 两个乘数末位之积的末位。

```
347×258 → 7×8=56 → 末位 6。若算出末位非 6，必然错。
```

## 五、速算心得

### 策略一：先看结构，再选武器

| 看到的特征 | 用这招 |
|-----------|--------|
| 两数都近 100 | 补数交叉法（技巧 7） |
| 两数以某数为轴对称 | 平方差乘（技巧 9） |
| 两数十位相同、个位和=10 | 首同尾合十（技巧 8） |
| 末尾有 5 或 0 | ×5/25 转换（技巧 3） |
| 出现 9/99/11 | 专用口诀（技巧 4/5） |
| 分子分母接近 | 差值法找 GCD |

### 策略二：先估算，再精算

```
任何计算前先做一步估算锁定范围：

  38×42 ≈ 40×40 = 1600，实际 1596，在你预期范围内。

  478÷19 ≈ 480÷20 = 24，实际 25.16。

估算帮你避开数量级错误。
```

### 策略三：验算是习惯，不是补救

```
每道计算都必须验，两道防线：
  ① 末位法（一眼的事，<1秒）
  ② 弃九法（10秒内，检测数字错位/漏进位）

两道都过，错的可能性极低。
```

### 策略四：背数据 → 形成条件反射

```
目标是让以下反应变成本能：

  看到 1/8 → 脑中蹦出 0.125
  看到 12×12 → 直接 144（不经过计算）
  看到 64 → 关联 4³ 和 8² 和 2⁶
  看到 2/3 → 脑中蹦出 66.7%
  看到 25×N → 自动 N×100÷4

背不是为了"知道"，是为了"不计算"。
```
